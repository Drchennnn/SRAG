# C02 · 范围与双语召回

## 结论

C02 实现已达到 C01 的范围、直读和词法召回条件，可送交独立审核。新路由为 `app.api.structure_search:router`，按 `/api/rag/structure` 前缀挂载后的入口是 `POST /api/rag/structure/search`。本项没有修改共享 `app/main.py`，由主控整合者在本项审核通过时加入路由。

实现保持 C02 边界。它支持当前可见版快照、服务端课程白名单、课程/文档/文件名范围、显式页或 Cell 直读、中英术语、缩写、代码标识符和完整的范围/查询/覆盖轨迹。结构邻接、同 Cell 输出扩展和纯图页浏览回退属于 C03，C02 对 `include_adjacency=true` 显式返回 422，不提前声称该能力。

## 实现内容

| 文件 | 作用 |
| --- | --- |
| `app/stores/structure_snapshot.py` | 使用一个 SQLite WAL 读事务固定 B 部当前版。先解析文档范围，歧义、缺文档或缺文件名在读取来源正文和 FTS 前结束。 |
| `app/rag/structure_search.py` | 定义类型化请求/响应，处理一基页、零基 Cell 索引、Cell ID、范围、歧义、术语变体、FTS 排名、精确代码复核和覆盖轨迹。 |

| `tests/test_structure_search.py` | 8 个隔离用例覆盖授权、路径脱敏、双向单语种术语、缩写、点号代码、跨课同名、页/Cell 直读、非法位置、两次换版快照和三格式公开样例。 |

## 关键行为证据

### 范围和授权

- API 依赖默认返回空白名单，未配置时实测为 403。测试通过 `dependency_overrides` 注入 `trusted`，不使用客户端 `course_ids` 扩大授权。
- 文档 ID 和文件名在已允许课程内取交集。跨课程同名 `common.ipynb` 返回 `ambiguous_scope`，候选只含 `course_id, document_id, version, file_name`。
- HTTP 快照、范围轨迹和歧义选项只返回 basename。用例传入 `/workspace/private/common.ipynb` 后，轨迹仅保留 `common.ipynb`；对隔离库响应序列化后检查，未出现本机课程根目录。
- 无效文档、缺失文件名和歧义在首个文档快照后结束。对歧义用例，`enumerated_source_count=0`、`fts_seed_count=0`。

### 直读和快照

- 直读请求向快照层传入 `fts_match=None, fts_limit=0, require_single_document=true`，不在整份文件上运行 MATCH 后丢弃结果。C02 只返回目标页或 Cell 的基层来源，同页对象和同 Cell 输出留给 C03。
- 显式页查询在目标来源文字内做局部变体核对，返回 `location_text_matched`。覆盖轨迹分别记录快照内枚举的来源数、实际核对的证据数和最终返回数。
- 同一资料先发布 v1 `oldversionword`，完成一次快照，再发布 v2 `newversionword` 并完成第二次快照。第一次响应的 snapshot 和候选全为 v1，第二次全为 v2，v2 发布后旧词返回 `empty`。

### 双语、缩写和代码

- “岭回归”查询限定到只含 `ridge regression` 的英文资料时命中，`ridge regression` 查询限定到只含独立术语“岭回归”的中文资料时也命中。轨迹保留 `raw` 和 `glossary` 变体及术语表版本 `c02-public-v1`。
- `FFT` 扩展到 `fast Fourier transform` 和已登记中文术语。首版中文支持限于术语表中独立、完整的词项，不声称 `unicode61` 能完成通用中文分词。
- `np.linalg.solve` 使用 `np, linalg, solve` 词元取得候选。只有 FTS 实际标题或正文中存在带标识符边界的完整字面串时才返回 `exact_literal`；只分开出现三个词时返回 `token_component`。

## 已知边界

- 快照适配器对已解析的文档范围枚举来源行，然后在同一快照内取 FTS 种子。覆盖轨迹已区分 `enumerated_source_count`、`evidence_inspected_count` 和 `returned_count`，但本项没有测量大型课件的内存和延迟分布。
- 显式位置不运行 FTS MATCH，只对目标基层页或 Cell 做本地术语变体核对。页内对象、图注、同 Cell 输出和前后位置属于 C03。
- 文字无命中时 C02 返回 `empty`。单文件纯图页的有界浏览回退属于 C03。
- 术语表目前是最小公开 v1，只包含审核用岭回归和 FFT 组。它证明确定性双向扩展和轨迹，不是通用课程词典。
- API 在主应用中的路由整合仍由主控负责；独立 ASGI 用例已通过，本分支未修改 `app/main.py`。
