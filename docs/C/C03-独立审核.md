## 独立验收证据

### 同预算与一跳边

- 满 K 样例在 `K=3, C=9, R=1` 时，纯 FTS 为 `page:1:shape:1, page:2, page:3`，结构策略为 `page:1:shape:1, page:2, page:1`；两组均为 3 条，结构槽没有扩大最终预算。
- `K=1` 始终保留最强 FTS 种子，同时合并该来源已有的结构原因。
- 父级、登记图注目标、直接子级、同位置、前一位置和后一位置均保留原因码及种子三元组。
- 独立合成探针确认：同页登记图像即使没有 bbox 仍可用 `caption_target` 引入；跨页、跨 `document_id`、跨 `version` 的同名目标均不能形成强边。
- 第二跳来源不会因第一跳候选再被递归展开；每条实际边的目标和种子始终属于同一文档及版本。

### 显式位置、Notebook 输出和覆盖

- 显式页或 Cell 不运行全文 FTS，以基层来源为首项，仅引入该位置的登记目标、子对象和同位置对象。
- `cell_id=plot` 返回顺序为 `cell:0, cell:0:output:0, cell:0:output:2`。缺失的 output 1 没有被虚构或重新编号，两个输出均含 `child_object` 原因。
- 只有上述 Cell 与两个输出的资料返回全部三项，`full_file_read=true`；普通搜索与浏览回退保持 `false`。
- 真实主应用 HTTP 对两页 PDF 请求 `[1,3]`，得到实际检查 `page:1,page:2` 和缺位 `location_missing:page:3`；对 Cell 0–1 请求 `[0,2]`，得到实际检查 `cell:0,cell:1` 和缺位 `location_missing:cell:2`。两者均保留已找到来源。

### 纯图回退、空结果和原因轨迹

- 唯一文件无文字锚点时返回 `no_text_anchor`，候选为有界基层页/Cell，原因 `page_browse_fallback`，并记录 `visual_not_read`，没有声称 OCR 或视觉读取。
- 两页扫描样例在 `K=1` 时只返回 `page:1`，`truncated_by_reason.page_browse_fallback=1`；`checked_positions` 仍记录完整检查池。
- 多文件无锚点以及 `include_adjacency=false` 的纯 FTS 无命中均返回 `empty`，没有拿任意首页填充。
- 真实 `create_app()` 隔离库分别发布原生文字、`legacy_text` 与通过版本/哈希/代次校验写入的 enhancement，HTTP 实测得到 `fts_native / fts_legacy / fts_enhancement`，同时保留原始 origin。

## 剩余边界与交接

- 邻接只走一跳，不解决需要两跳以上才能到达的证据。
- 未登记图注目标时，同页对象只能作为 `same_position_object` 弱候选，不能宣称图注精确指向该对象。
- B 当前只写入 `native_text`、`legacy_text`、`enhancement` 三种 origin；若 B 将来增加 origin，必须同步扩展公共原因契约和回归，不能直接当作新签认原因。
- 页浏览回退没有读取图像；真实显示和读取对象由 D 部负责。
- 本项没有测量大型课件的内存和延迟分布。
