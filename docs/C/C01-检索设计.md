# C01 · 范围与结构检索设计

## 1. 结论与边界

C 部只读 B 部已发布的当前可见版本，输入问题、课程或文件范围以及可选的页或 Cell 位置，输出版本化候选来源、实际查找范围、每个候选的引入原因和未覆盖情况。跨层标识继续使用 A01 签认的 `(document_id, version, source_id)`，不另建 C 部 ID，也不把路径、标题、页码、Cell ID 或排名当作来源键。

C 部不读原件字节、不渲染页面、不裁图、不调用视觉模型，也不把候选命中等同于已读图。D 部只需消费 C 返回的 A01 来源三元组，C 不导入 D 的模块或数据类型。旧 `/api/rag/local/search` 和 `/api/rag/search` 保持现状，新能力使用独立的 `/api/rag/structure/search`。

## 2. 现状与需要补齐的缺口

B 部的 `local_documents.current_version` 是当前版指针，`local_sources` 保存页、页内对象、Cell 和 Notebook 输出及父子关系，`local_fts` 保存原生文字、旧包文字或经版本校验的增强文字。`LocalLibraryStore.search_local()` 已能按课程 ID 和文档 ID 过滤 FTS，但还有以下缺口。

- 当前命中不记录查过哪些课程、文件和版本，也不区分纯 FTS 候选与结构引入候选。
- 现有请求不能用一基页码、原始 Cell 索引或 Cell ID 直读，也不能显式返回文件同名歧义。
- `unicode61` 只提供 Unicode 词法切分，不会自动把“岭回归”和 `ridge regression` 当作同一术语，也不足以独立保存 `np.linalg.solve`、`C++` 等代码符号语义。
- `current_sources()` 与 `search_local()` 分开调用时，两次短连接之间可能换版，不能用来构造一条可审计的结构检索轨迹。

## 3. 请求契约

### 3.1 结构请求

`StructureSearchRequest` 包含以下字段。

| 字段 | 约束与语义 |
| --- | --- |
| `query` | 可选字符串。没有显式位置时必须有非空查询；直读位置时允许为空。 |
| `scope.course_ids` | 一个或多个非空课程 ID，必填。API 依赖先取得服务端信任的课程白名单，只在客户端请求与白名单的非空交集内检索。 |
| `scope.document_ids` | 可选的稳定文档 ID 列表。一旦给出，只匹配同时属于 `course_ids` 的当前可见文档。 |
| `scope.file_names` | 可选的人类文件名列表。仅与 `source_path` 的 basename 做 NFKC、去首尾空白和不区分大小写的完整匹配，不做子串或模糊匹配。 |
| `location` | 可选。`page`、`page_range`、`cell_index`、`cell_range` 和 `cell_id` 五选一。 |
| `top_k` | 最终证据预算，默认 8，范围 1–50。纯 FTS 对照和结构结果共用这一预算。 |
| `include_adjacency` | 默认 `true`。`false` 仅返回直读或纯 FTS 候选，用于同预算对照。 |
| `include_page_fallback` | 默认 `true`。只在范围唯一确定到一个文档且文字无命中时，允许返回按页或 Cell 浏览候选。 |

`page` 和 `page_range` 用用户可见的一基页号。`cell_index` 和 `cell_range` 使用 Notebook JSON 的零基原始 Cell 索引，不是过滤后的代码 Cell 序号。`cell_id` 使用原文件中的 Cell ID。范围两端均包含，页范围不超过 20 页，Cell 范围不超过 50 个，起点大于终点或超限直接返回 422。位置直读要求范围最终唯一确定到一个文档，避免把“第 2 页”同时应用到多份资料。

`document_ids` 是权威选择器，`file_names` 是便利选择器。两者同时出现时取交集。文件名在一个课程内或跨课程匹配到多个文档时，不猜测，返回 `ambiguous_scope` 以及每个可选的 `course_id`、`document_id`、当前 `version` 和文件名。客户端可以用 `document_id` 重试。

`app/api/structure_search.py` 使用 `get_structure_course_allowlist()` 依赖取得信任范围。默认配置是空集且关闭访问，部署必须从服务器信任配置给出非空白名单才能检索。客户端的 `course_ids` 不会扩大该白名单，交集为空时返回 403，不通过歧义或空结果暴露课程是否存在。测试通过 FastAPI `dependency_overrides` 显式注入隔离课程，不修改全局环境或把请求字段当成授权。

### 3.2 位置直读

- 页直读先选取 `locator.page` 等于目标页的页级来源，再按 `ordinal, source_id` 列出同页子对象。页级来源是主候选，子对象的原因为 `same_page_object`。
- Cell 直读先选取 `locator.cell_index` 或 `locator.cell_id` 匹配的 Cell 来源，再列出其已保存输出。同 Cell 多图按 B 部保存的输出顺序返回，不把“第二个输出”解释成单张图内的第二个子图。
- 旧式 Notebook 没有 Cell ID 时，`cell_id` 查找返回 `location_not_found`，`cell_index` 仍可使用。
- 显式页或 Cell 存在但文字为空时，仍返回该来源，标记 `text_available=false` 和 `direct_location`，不伪造 FTS 命中。
- 显式位置与查询同时出现时，位置先限定候选集，查询只用来在该位置内排序和记录文字是否命中，不跳到别页或别的 Cell。

## 4. B 部当前快照读取接口

### 4.1 新增存储接口

`app/stores/structure_snapshot.py` 中的 `StructureSnapshotStore.read(request: StructureSnapshotRequest) -> StructureSnapshot` 是 C 对 B 表的唯一新读取面。该独立只读适配器复用 `MetadataStore` 的连接管理和 `promote_due()`，不修改当前由其他分支共享的 `app/stores/local_library.py`。它不暴露 SQLite 连接，不返回原件 BLOB，也不允许 C 更改发布指针。返回内容包含以下三类不可变值。

1. `documents` 在内部记录 `course_id, document_id, version, publication_epoch, content_sha256, source_path, title` 和格式。`source_path` 仅用于同名解析，HTTP 响应和公开轨迹只显示 `file_name=Path(source_path).name`，不返回本机目录。
2. `sources` 记录候选池所需的 `source_id, parent_id, ordinal, kind, title, text, locator, state`。
3. `fts_seeds` 记录词法命中的来源键、`origin`、BM25 分数和命中查询变体。

该方法在同一个连接中完成如下步骤。

1. 用一个固定 `cutoff` 调用 `promote_due()`，使到期发布在快照前完成。
2. 显式 `BEGIN`，第一条查询读取符合课程和文件选择器的 `local_documents` 当前版，固定 SQLite WAL 读快照。
3. 仅以上一步固定的 `(document_id, current_version)` 连接 `local_versions`、`local_sources` 和 `local_fts`。所有查询都同时带 `deleted=0`、服务端允许的课程范围和固定版本条件。
4. 在取得直读来源、FTS 种子和种子的有界邻接行后结束读事务。

这个顺序保证一个响应不会同时包含 v1 的 FTS 种子和 v2 的邻接对象。读快照期间发生的换版可以在后续请求看到，本请求仍返回已固定的版本和 `publication_epoch`。下游如果需要当前原件，仍必须用来源三元组重读，不能仅凭 C 的旧排名结果猜测当前版。

### 4.2 范围解析结果

范围解析仅有以下四类结果。

| 结果 | 行为 |
| --- | --- |
| `resolved` | 返回一个或多个已授权当前版，继续检索。 |
| `ambiguous_scope` | 文件名匹配多份资料且请求需要唯一文件，返回可选列表，不执行 FTS 或直读。 |
| `scope_not_found` | 文档 ID 不属于允许的课程、文件名不存在，或文档已删除，候选为空。 |
| `location_not_found` | 文件存在，但页号、Cell 索引或 Cell ID 不存在，候选为空，返回已知的最小和最大位置供纠正。 |

这些状态用 200 返回，因为它们是可预期的检索结果。结构不合法、范围超限和互斥位置同时出现用 422。快照忙超时或库损坏不降级为空结果，保留服务器错误以便监测。

## 5. 词法检索与双语处理

### 5.1 确定性查询构造

C02 首版不调用模型改写，只用可重放的归一化和术语表。处理顺序如下。

1. 保留原查询作为 `raw_query`，对用于匹配的副本做 NFKC 和不区分大小写处理。
2. 从可版本化的双向术语表生成变体。例如 `岭回归 ↔ ridge regression ↔ ridge`、`快速傅里叶变换 ↔ fast Fourier transform ↔ FFT`。术语表项可限定 `course_id`，通用项不覆盖课程项。
3. 保留原查询中的英文原词、缩写、数字、希腊字母和代码标识符。对 `np.linalg.solve` 产生 `np, linalg, solve` 的 FTS 词元作为候选查找，只有在命中的 `local_fts.body` 或 `title` 中以标识符边界复核到完整字面串 `np.linalg.solve` 时，才记录 `match_kind=exact_literal`；否则只记录 `match_kind=token_component`。对 `C++` 、`C#` 等符号型词使用术语表中的可检索别名，不把 FTS 丢掉的标点当成已命中。
4. 对每个变体使用引号转义后的 FTS5 参数，程序构造 `OR`，不接受客户端传入的 MATCH 语法。变体去重且上限 16 个，超限时优先原词、精确术语和课程术语。

响应的 `query_trace` 保留 `raw_query`、实际使用的 `variants`、每个变体的 `reason` 和术语表版本。否定词只记录为 `negation_detected=true`，C 部不把“不要”解释成排除某来源，避免因简单删词造成漏检。否定语义留给后续有证据绑定的回答层，C04 需确认否定问句仍保留相关候选。

### 5.2 纯 FTS 基线

纯 FTS 基线只排序当前快照中的文字命中，去重键为来源三元组。同一来源有原生文字和经校验增强文字时合并为一个候选，保留所有 `origin`。排序先按 BM25，再按 `document_id, ordinal, source_id` 保证重放稳定。纯 FTS 返回前 `top_k` 个，不额外返回父页或相邻页。

## 6. 有界结构邻接

### 6.1 图与原因码

结构扩展只沿 B 部已登记的同文档、同版本边走一跳，不跨文件自动扩展。

| 原因码 | 从种子到候选的关系 |
| --- | --- |
| `direct_location` | 用户显式指定页、页范围、Cell 或 Cell 范围。 |
| `fts_native` / `fts_legacy` / `fts_enhancement` | 候选的对应文字行被 FTS 命中。 |
| `parent_context` | 页内对象或 Notebook 输出命中后引入其父页或 Cell。 |
| `child_object` | 页或 Cell 命中后引入直接子对象或已保存输出。 |
| `caption_target` | 命中已登记的图注来源后，引入其 `locator.caption_target_source_id` 指向的同版页内对象。 |
| `same_position_object` | 引入同一页或同一 Cell 且与种子共享位置的其他对象。 |
| `previous_position` / `next_position` | 页级或 Cell 级种子的紧邻前后一个基层位置。 |
| `page_browse_fallback` | 唯一文件内无文字种子时，提供有界的页或 Cell 浏览入口。 |

“同一位置”优先用 `parent_id`，其次使用已验证类型的 `locator.page` 或 `locator.cell_index`。不用标题相同或序号接近猜测父子关系。图注到对象的强关系只接受 B 表中已注册的 `locator.caption_target_source_id`，并校验目标键存在于同一 `(document_id, version)` 且页号相同。公开探针用显式注解的图注来源和对象来源验证此边。如果没有注册指向，只能用 `same_position_object` 作为较弱的同页回退，不从图注文本、对象标题或词法相似度猜测对应对象。结构引入顺序固定为父级、已注册图注目标、直接子级、同位置对象、前一位置、后一位置，同类内按 `ordinal, source_id`。

### 6.2 同预算对照

设证据预算为 `K=top_k`，两策略共用固定的 FTS 候选检查上限 `C=min(3K, 150)`。纯 FTS 对照在前 C 个 FTS 来源中返回前 K 个。结构策略查看同样的前 C 个 FTS 种子及其一跳邻接，最终仍只返回 K 个来源。当实际 FTS 命中少于 C 时，两策略检查的 FTS 数都以实际命中数为准。

为防止前 K 个种子占满结果而使邻接策略恒退化为 FTS，结构策略使用确定性保留槽。`K=1` 时始终保留最强 FTS 种子。`K>1` 且存在合法邻接时，保留 `R=min(max(1, floor(K/3)), 4, K-1)` 个邻接槽，先放入最强 FTS 种子，再用其他 FTS 种子填满 `K-R` 个种子槽，最后按父级、已注册图注目标、直接子级、同位置、前后位置的顺序填邻接槽。不足 R 个合法邻接时，剩余槽依 FTS 排名回填。显式位置直读不使用这个保留公式，它以目标位置为主候选，同样受 K 限制。

同一来源只返回一次，但保留全部 `reasons` 和对应种子键。候选因 K 截断时，`coverage.truncated=true` 并记录未返回的各原因数量。比较报告同时记录 C、K、R、实际 FTS 命中数和实际邻接数，两组的最终证据数均不超过 K。

### 6.3 纯图和空结果

显式页直读总能返回已登记的空文字页，这是“可查看该页”，不是“问题已命中该页”。查询无 FTS 种子时只在范围唯一文件且开启回退时，返回前 K 个基层页或 Cell，原因为 `page_browse_fallback`，状态为 `no_text_anchor`。多文件范围无命中时返回 `empty`，不用任意文件的首页填充结果。

页浏览回退不会自动发起 OCR 或视觉读取。响应明确建议下游让用户指定页或从缩略图中选择，并保留 `text_available=false`。

## 7. 响应与覆盖轨迹

`StructureSearchResponse` 包含以下字段。

| 字段 | 内容 |
| --- | --- |
| `status` | `ok`、`ambiguous_scope`、`scope_not_found`、`location_not_found`、`no_text_anchor` 或 `empty`。 |
| `snapshot` | 本请求实际读到的每个 `course_id, document_id, version, publication_epoch, content_sha256`。 |
| `scope_trace` | 请求课程、服务端允许课程的交集、文件选择器、名称解析结果、实际查找的文档和位置范围。文件只显示 basename。 |
| `query_trace` | 原查询、变体及原因、术语表版本、否定词标记。 |
| `candidates` | 候选来源三元组、课程、定位、类型、文字可用性、FTS origin 和分数、全部引入原因与种子键。 |
| `coverage` | 快照文档数、可检索来源数、FTS 种子数、实际检查的邻接边数、返回数、各原因被截断数和是否完整读取文件。 |
| `misses` | 请求但未找到的页或 Cell，以及已知的文字无命中、无可靠邻接锨点等原因。 |

`coverage.full_file_read` 只在直读请求显式覆盖文件的全部基层页或 Cell，且该版本所有来源都被返回时为 `true`。普通 FTS 和邻接检索总是 `false`。`coverage.checked_positions` 记录实际检查的页或 Cell 集合，避免把“查了候选”误报成“读完全文”。

## 8. 公开样例与验收矩阵

C 部使用 `docs/A/样例/` 中的三格式公开原件及 C 部自建的小型公开探针，不读取或复制 A03 私有题集与答案。所有探针在隔离 SQLite 和隔离数据目录中重建资料。

| 用例 | 输入 | 预期关键证据 |
| --- | --- | --- |
| PDF 英文原词 | `lookahead`，限定 PDF 文档 | 纯 FTS 命中 `page:1`，三元组、版本和范围轨迹完整。 |
| PPTX 英文原词 | `Peak`，限定 PPTX 文档 | 命中 `page:1:shape:3`，结构策略可引入父页并标记 `parent_context`。 |
| Notebook 代码标识符 | `NotebookImage`，限定 Notebook | 命中 `cell:1`，结构策略在预算内列出同 Cell 的已保存输出。 |
| Cell 直读与多图 | `cell_index=1` | 返回 Cell 及同 Cell 多输出，顺序稳定，无需查询文本。 |
| 换版快照 | 检索 v1 期间并发发布公开 v2 Notebook | 一个响应内的种子、邻接和快照全部是 v1 或全部是 v2，不得混版。 |
| 中文查英文单语料 | 英文专用文档只含 `ridge regression`，用“岭回归”查询 | 命中必须来自版本化术语表的英文变体，不能依赖源文中同时存在中文。 |
| 英文查中文单语料 | 中文专用文档只含“岭回归”，用 `ridge regression` 查询 | 命中必须来自中文变体。因 `unicode61` 不提供通用中文分词，首版只保证术语表中完整、已隔离验证的中文术语，不声称任意中文子词召回。 |
| 缩写与代码 | 自建文本含 `fast Fourier transform`, `FFT`, `np.linalg.solve` | 英文全称、缩写和代码标识查询都保留实际使用变体；只有复核 FTS 原文后才把点号完整串记为精确命中，不执行代码。 |
| 注册图注关系 | 公开小型探针含图注来源、目标页内对象及 `caption_target_source_id` | 图注命中后用 `caption_target` 引入指定对象；删除注册指向后只能出现较弱的 `same_position_object`，不从文本猜测。 |
| 跨课程同名 | 在 `course-a` 和 `course-b` 各导入一份同名公开样例 | 只按名称且范围包含两课时返回 `ambiguous_scope`；指定课程或 `document_id` 后不越界。 |
| 显式页 | `page=1`，查询留空 | 页级来源为 `direct_location`，同页对象的引入原因可追溯。 |
| 页范围 | `page_range=[1,2]` 和反向或超限范围 | 合法范围只读目标页；反向或超限返回 422。 |
| 纯图页 | 自建一页空文字但已登记的 PDF 探针 | 显式页直读返回页键且 `text_available=false`；文字查询只能给出 `no_text_anchor` 浏览回退。 |
| 空结果 | 唯一不存在的探针词，跨多文件范围 | `status=empty`，候选为空，快照和检查范围仍存在，不任意返回首页。 |
| 否定问句 | “哪一页不是在讲 FFT” | C 保留 FFT 相关候选并标记否定，不声称已完成语义排除。 |

## 9. 精确测试与失败条件

### C02 定向测试

- 快照读取在换版竞争下不混合 `version`、`content_sha256` 和 `publication_epoch`。
- 课程 ID、文档 ID 和文件名选择器按交集生效，已删除或其他课程文档不可见。
- 服务端课程白名单默认关闭，非空交集才可检索；测试用依赖覆盖注入范围，公开轨迹不泄露绝对路径。
- 跨课程同名返回可重试歧义，不选排名最高的那份。
- 一基页、零基 Cell 索引、Cell ID、合法范围、不存在位置和超限范围均有独立断言。
- 中文术语、英文原词、缩写、希腊字母和代码标识符保留变体与命中轨迹。
- 中查英和英查中分别使用单语种源文验证；点号代码词组只有在 FTS 原文复核完整字面串后才声称精确命中。

### C03 定向测试

- 父子、同位置、前后位置每类边都检查同文档同版本约束和原因码。
- 同 Cell 多输出按 B 部 ordinal 和来源 ID 稳定返回，缺输出不创建虚拟候选。
- 纯 FTS 与加邻接的最终候选数都不超过 K，结构策略不越过一跳。
- 两策略的 FTS 检查上限都是 C；当前 K 个 FTS 种子已占满时，R 个保留槽仍可确定性引入合法的父级、注册图注目标或子对象，同时始终保留最强 FTS 种子。
- 注册图注边、无注册边的同页回退和仅文本相似三种情况分开，仅第一种可记为 `caption_target`。
- 纯图页显式直读、单文件浏览回退和多文件空结果三者分开。
- `full_file_read`、`checked_positions`、被截断原因和漏检列表与实际 SQL 读取相符。

### 必须判为失败的情况

- 响应候选缺少三元组，或三元组所在版本不在 `snapshot` 中。
- 用路径、文件名、页码、Cell ID 或排名替代 `source_id`。
- 一条响应混合两个可见版，或返回已删除、待发布版的来源。
- 文件同名时静默选一份，或以客户端传入的 `course_id` 绕过服务端范围。
- 结构策略比纯 FTS 返回更多最终来源却声称同预算改善。
- 结构候选没有原因或种子键，邻接跨文件、跨版本或超过一跳。
- 纯图页因可以展示而被记为文字命中或已视觉读取。
- 空结果丢失实际查找范围，或在多文件中用无关首页填充候选。
