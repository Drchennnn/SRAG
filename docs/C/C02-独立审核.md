## 验收证据

| 条件 | 独立结果 |
| --- | --- |
| 白名单与只读范围 | 未配置 `SRAG_STRUCTURE_COURSES` 时真实 HTTP 返回 403；配置 `public` 后同一请求返回 200。客户端课程范围只与服务端白名单取交集。 |
| 路径脱敏 | HTTP 的快照、范围和歧义选项只含 basename；隔离课程根绝对路径及 `private/folder` 未出现在序列化响应。 |

## 剩余边界与交接

- 术语表是公开最小版本，只证明已登记术语的确定性双向扩展，不代表通用中文分词或完整课程词典。
- C02 的普通检索会在固定快照内枚举所选文档来源并执行有界 FTS，但没有测量大型课件的内存和延迟分布。
- 本项不签认结构邻接、图注关系、同 Cell 输出、纯图页浏览回退或视觉读取；这些能力分别由 C03、C04 和 D 部验证。
- `app/main.py` 是共享整合文件。本报告签认其 C02 路由接入字节；后续 D 路由串行接入后应由对应任务重新记录共享文件版本，不改变本表其余 C02 封存文件。

C02 可以进入治理记录、按任务号提交并推送。只有远端 SHA 回读确认后，C03 才可开放。
