## 二、首轮盲测 `M1` 发现的 3 处阻塞性缺陷（脱敏报告，严守零泄密）

在未见试点课程上运行独立构建器（[app/stores/local_kg.py](file:///Users/Link/code/SRAG-h/app/stores/local_kg.py)）时，所有 5 类“仅共享术语”反例与跨课程隔离均正常拒收（0 误接受），但**真边抽取与概念规范化命中以下 3 个客观代码缺陷**，导致 `M1` 未达标而中断后续门禁：

### 缺陷 1：`_SECTION_BOUNDARY_LINE` 把 PDF 折行行首小数误判为章节边界，截断实验锚点（`local_kg.py#L96-L99`、`#L715-L717`）

- **代码根因**：`_SECTION_BOUNDARY_LINE` 使用 `(?:§[ \t]*)?\d+(?:\.\d+)+[.)]?[ \t]+\S` 匹配多级节编号。当 PDF 原生文本在数学/阈值条件处发生自动换行，下一行以带单位的小数（如 `0.05 s ...`、`0.85 ...`）开头时，正则将该小数行首误判为新节边界，提前截断 `[s_start, boundary_end)`。
- **后果**：位于条件段之后的显式实验演示声明句被截出概念作用域之外，伴随实验符号未被收入 `anchor_terms_json`，进而导致依赖跨文件符号核验（E2）的 `demonstrated_by` 真边**整条漏抽**。
- **必改要求**：节编号匹配须要求首段为非零正整数 `[1-9]\d*`（不匹配 `0.xx` 小数），并排除行内含单位/逗号/句号/分号等长句特征的普通折行。

### 缺陷 2：“独立概念定义标题行 + `正式定义：` 正文行”被错误拆块、产生垃圾概念及公式减号误切（`local_kg.py#L89-L95`、`#L480-L506`、`#L567-L588`、`#L645-L679`）

- **代码根因**：
  1. 当讲义按“第 1 行：`1. 核心概念定义：<概念名> (<英文别名>)`（无同行正文），第 2 行：`正式定义：...`”排版时，`_split_logical_blocks()` 因 `_is_non_title_prev()`（第 501 行）将第 1 行判为 `_D1_HEADER_LINE` 而拆成两个独立块。随后第 1 块因无正文使 `_D1_HEADER_LINE` 失败，落入第 671 行 `_D1_INLINE_RULE_LINE`，把标签内部前缀（如 `"核心概念"`）当成独立概念名写入库中；
  2. 当两行同属一个块（如 PPTX 标题行 `"概念定义：<概念名> (<别名>)"` 后接 `"正式定义：..."`）时，第 651–665 行取 `prev_title` 时未剥离前导 D1 定义标签（如 `"概念定义："`），导致生成的 `canonical_name` 带有标签前缀；
  3. 当第 2 行 `"正式定义：..."` 以常规动词或数学传递函数/方程开头（如 `"正式定义：采用 ... F(z) = (1 - 2 ...)"`）而非 `_D1_CONDITION_START` 引导词时，`_split_d1_rest()`（第 574 行）未优先回绑上一行的概念标题，反而被 `_D1_INLINE_SEP`（`\s+[—–-]{1,2}\s+`）**命中了数学公式中的减号 `" - "`**，直接把半截数学公式切作概念名称。
- **必改要求**：
  1. `_D1_INLINE_RULE_LINE` 与 `_clean_term_and_aliases` 严禁将 `核心概念`、`概念`、`正式`、`基本` 等纯标签词当成概念名；
  2. `_clean_term_and_aliases`（及 `prev_title` 提取）须剥离前导 D1 标签前缀（如 `概念定义：`、`核心概念定义：`、`Formal Definition:` 等）；
  3. 当紧邻前一行或前一个单行概念标题块为纯概念标题（如 `1. 核心概念定义：<概念名>` / `概念定义：<概念名>`，无同行正文）且下一行紧接 `正式定义：...` / `Formal Definition: ...` 时，须合并归属为同一概念块并优先以标题行概念名为准；`_D1_INLINE_SEP` 中的连字符 `-` 严禁在等号/括号公式上下文中作为标题-正文分隔符。

### 缺陷 3：PDF 跨行折断的长标题括号别名截断（`local_kg.py#L81-L88`、`#L658`）

- **代码根因**：`_D1_HEADER_LINE` 中 `(?P<rest>[^\r\n]+)` 只捕获单行；当 PDF 解析在英文括号别名内部换行（如 `1. 核心概念定义：<中文名> (Multi-Word English\nAlias)`）时，标题行在 `\n` 处被截断，留下未闭合左括号 `(`，导致 `_PARENS_ALIAS` 失效并把残缺英文前缀留在 `canonical_name` 中。
- **必改要求**：若 D1 标题行末尾存在未闭合的 `(` / `（` 且紧随下一行完成闭合 `)` / `）`，须先续接闭合括号再进行概念名与别名解析，同时保持 `evidence_span_start..end` 对原文字符偏移的 100% 精确一致。
