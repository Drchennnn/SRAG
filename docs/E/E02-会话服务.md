# E02 · 持久会话与回答服务

E02 按 [E01](./E01-会话与回答设计.md) 与 [本轮证据接口](./本轮证据接口.md)
实现了浏览器 HTTP 和终端共用的本地服务。实现以 E01 远端回读版本
`860f4f7c79321d4deb880e19a578be434ca48c2f` 为起点。E03 的页面独立开发，本报告先核验
后端 JSON、SQLite 生命周期和 B/C/D 读取行为。

## 入口与实现

- `app/api/workspace.py` 提供 `/api/workspace` 路由。仅接受 loopback Host，从有效的
  同源请求或终端凭据建立授权。首次同源空会话申请生成随机 owner，向浏览器发
  HttpOnly 和 SameSite=Strict cookie。SQLite 存 owner 摘要。格式错误和跨所有者的
  请求走统一拒绝分支。媒体响应是实际栅格字节，缓存指令为 `private, no-store`。
- `app/stores/workspace.py` 在 B 使用的 SQLite 文件中增量保存会话、轮次、消息和
  媒体。预约、终态、重试与取消通过事务和 attempt 校验。写终态前在同一写事务
  比对范围修订、有效课程、固定文档的当前版本、原件哈希和发布代次。版本切换
  或旧 attempt 晚到时释放待提交证据。终端和浏览器的所有者保持独立。
- `app/rag/workspace.py` 由实际 B 快照生成目录。资料、章节、页、Cell 和对象的
  节点标识绑定会话、当前版本、原件哈希与发布代次。问答调用 C 查找并从 B
  重读有据可依的原文，视觉展示由 D 渲染。它可以离线给出可核对摘录和部分
  摘要，视觉问题调用 D 定向读图，真实或明确许可缓存的视觉结果才作为事实。
  每个保存的媒体记录核对 D 字节哈希。历史读取仅由所属消息的显示引用进入，
  打开同版媒体或原页，原件授权撤回后去除对外证据、引文、候选、解析轨迹及选项。
- `python -m tools.workspace_chat` 直接使用同一服务。旧 `tools.chat` 与
  `/api/rag/*` 沿现有路径运行。显示有序块用 `GET /sessions/{s}` 恢复，普通
  POST 可用查询快照、取消和重试端点观察状态。API 不接受客户端指定方框、来源
  三元组或主机文件路径来读取消息媒体。上传只从请求体写入独占临时目录并交 B 导入。

## 公开样例结果

用 FastAPI 测试客户端向独立数据库导入真实 `Signal-lab.ipynb`，Cell 2 出现在
`Median filter lab` 章节中。读到两个真实图片的原始字节，源位置依次为
`cell:1:output:1` 与 `cell:1:output:2`。两图片之间即使插入失败块，失败块也不占可见序号。
同一图片出现两次时，两个显示 ID 独立。各 HTTP 路径都验证刷新后持久序列。

| 操作 | 实际结果 |
| --- | --- |
| 点目标卡后输入“横轴是什么？” | 请求有 message/display 引用，解析为该卡实际对象并记录 `display_anchor`。 |
| 直接输入“刚才第二张图” | 请求仅含类型、文本、轮次 ID 与范围修订。服务从已完成消息按显示顺序找第二图，轨迹为 `visible_ordinal`、`ordinal=2` 与 `cell:1:output:2` v1。 |
| 只输入“那张图的单位？” | 同一会话中出现两个持久澄清选项；刷新后选第二项时记录 `clarification_choice`。 |
| 原件换至 v2 后回看上一条消息 | 历史媒体字节仍等于 v1 蓝图；旧目录节点无权解析到 v2。再次明确选当前内容会得到 v2。删除后旧媒体返回 404，轨迹和派生文本也被脱敏。 |
| 切换文件、独立会话、取消与重试 | 新摘要只引用所选文件，合法旧媒体可回看；同 owner 的两会话和独立 owner 均验证隔离。相同轮次的并行重复请求得到同一轮，常规重复请求不重试。取消后迟到结果不写回复，断开的旧 attempt 可在租约失效后恢复。 |

测试关闭模型和凭据。读图路径可选择和展示原件，证据保持 `not_attempted`、
外部视觉调用为 0。E04/E05 在真实浏览器和真实应用环境中进一步取证。图像读取
D 原件渲染及原生文字读取在 E02 测试已实际执行，故障与重复图出现数由测试注入。
F 的二跳仍可通过共享证据接口独立开发；E02 问答目前使用经核验的单跳证据。

## 独立首审问题的修正

- 摘要先查基层页或 Cell，并以实际原生读取状态计算覆盖。未读纯图、读取失败、
  摘录截断和超出读源预算均标明部分来源。公开 PDF 文字页与临时生成的扫描页组合导入后，
  `base_source_count=2`、`full_text_scope=false`，第 2 页缺项原因是 `needs_ocr`。
  另以七个 Cell 检查首 Cell 摘录截断与末 Cell 超出预算的轨迹。
- 展示上限为三张有效图，独立的渲染尝试上限为十二项。公开 Notebook 在正常两图前
  插入两个合法 Base64 但内容损坏的 PNG，D 尝试四项、失败两项、有效展示两张。
  失败卡未占序号，纯文字“刚才第二张图”解析到实际后一个输出 `cell:1:output:3`。
  轨迹保存尝试、失败、有效展示和未尝试计数。
