# E05 · 网页与持久会话独立整审

## 审核结论

**通过。** 审核者 `ef_gate` 未参与 E 部设计或实现。受测应用来自公开 E04 提交
`4d523ca49bebb9231e69014ad0167c571cfd1342` 的精确归档，只加入本次审核的浏览器脚本
和故障运行器。两套新的 Chromium 会话访问同一真实 FastAPI 应用，使用临时 SQLite、
课程目录和图像缓存。公开资料取自 `docs/A/样例/`。外部模型关闭，三次定向追问均记录
`external_call_count=0` 与 `not_attempted`。

本次浏览器实测 11 次提问或总结提交及 6 次导入、重试或取消均返回 HTTP 200。
两位 owner 均可打开自己的会话和当前原件。双向读取对方会话与对方原件共四次，均返回
HTTP 404。SQLite 对受测的两个会话核对出两个 owner 摘要。

## 浏览器实测

| 场景 | 实测 |
| --- | --- |
| 两张图与纯文字追问 | A 在网页导入 Notebook v1，打开 Cell 2 并发问。浏览器解码两张 440×260 PNG，DOM 实显 ID 顺序与完成消息保存顺序一致。只输入“刚才第二张图”的实际 POST 包含 `client_turn_id`、`kind`、`text`、`scope_revision`。服务以 `visible_ordinal` 解析该消息第二个显示 ID。 |

| 歧义和刷新 | “那张图”返回两项澄清。刷新后两项仍在，点第二项后服务以 `clarification_choice` 解析为第 2 张图，原消息与显示 ID 和前两条途径一致。 |
| 切换文件与摘要 | A 切至同课程的 `Signal-reference.pdf` 后执行单文件总结，追踪只含该 PDF 的文档 ID。刷新后恢复此范围和已完成的单文件摘要。 |
| 发布新版本与查看历史 | A 在网页选择替换当前 Notebook，上传同名公开 v2。文档 ID 保持一致，新消息展示 v2。刷新后从原有消息点旧图，阅读器标题仍为 `Signal-lab.ipynb · v1 · 输出 2`，图像可解码。两版浏览器收到的 PNG 分别与对应原件中的保存字节一致。 |
| 并行与双会话隔离 | B 在 `isolation` 课程选定自己的 PDF，并在 A 执行中的轮次尚未取消时完成第二问。B 刷新后恢复两次回答及单 PDF 范围，A 的 Notebook 操作和换版未改变 B 的范围。 |

在带有本次审核文档的仓库执行以下命令。机器需有该项目的 Python 环境和已可启动的
`agent-browser` Chromium。脚本会创建临时数据目录，成功时打印输出目录。

```sh
srag_root="$(pwd)"
srag_audit="$(mktemp -d /tmp/srag-e05-review.XXXXXX)"
git archive 4d523ca49bebb9231e69014ad0167c571cfd1342 | tar -x -C "$srag_audit"
cp docs/E/E05-browser.sh docs/E/E05-server.py "$srag_audit/docs/E/"
cd "$srag_audit"
SRAG_PYTHON="$srag_root/.venv/bin/python" E05_PORT=18822 \
  E05_BROWSER_PREFIX=srag-e05-independent-r2 bash docs/E/E05-browser.sh
PYTHONDONTWRITEBYTECODE=1 "$srag_root/.venv/bin/python" -m pytest -q -p no:cacheprovider \
  tests/test_workspace.py tests/test_dialogue.py tests/test_summary.py tests/test_rag_api.py tests/test_chat.py
```

新终端通过 `tools.workspace_chat` 在同一隔离数据库中实际搜索 `lookahead`，在
`isolation` 的单份 PDF 范围命中第 1 页。旧 `tools.chat --help` 可用，原 CLI 范围、
引用和日志契约由定向回归复跑。回归共 101 项通过，保留一条既有的 Starlette TestClient
弃用提示。Ruff、Bash 与 Node 语法检查通过。
