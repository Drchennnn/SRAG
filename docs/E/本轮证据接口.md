# E/F · 本轮证据接口

适用基线为已回读的 `69a3a9e6d880e56ffa5821904b90e74a9b236661`。E 拥有会话、消息和展示顺序，F 拥有补检索策略与本轮证据预算。Codex 主会话整合接口，代码使用独立的 `app/schemas/turn_evidence.py`。E02 实现此数据面，F02 可依本文和公开样例独立核验。

## 共同数据面

| 类型 | 核心字段与约束 |
| --- | --- |
| `TurnScope` | `course_ids` 和 `document_ids`。两者都是服务端解析且获准的非重复标识。取得初次快照后，显式固化实际文档集合；空集合表示无资料。历史授权范围另存。 |
| `SourceRevision` | `source: SourceKey`、`course_id`、`publication_epoch`、`content_sha256`。沿用 A 的 `(document_id, version, source_id)`，不得用排名、文件名、页或 Cell 序号代替。 |
| `TurnRead` | `actual_source: SourceKey`、`method`、`status`，及 `text`、`warnings`。原生读取保存实际摘录；D 视觉读取另存 `execution`、`actual_input_sha256`、`actual_input_media_type`、`actual_input_rect`、`model`、`prompt_version` 和 `question_sha256`。 |
| `TurnEvidence` | 本轮唯一 `evidence_id`、`revision: SourceRevision`、`file_name`、`locator`、`read_status`、`reads: list[TurnRead]`。记录原请求对象，以 `reads[].actual_source` 核对实际对象；必须是同一资料同一版本。 |

`method` 取 `native_text | native_table | ocr | vision`。读取状态沿用
`not_attempted | succeeded | partial | failed`。原生文字只有经 B 当前版本网关读取且摘录非空时才可标记
`succeeded`。C 候选及 FTS 摘要只是线索，重读前为 `not_attempted`。D 的 `display` 与 `reads`
分别进入消息展示与读证据。只有真实模型成功或带真实来源的有效缓存支持视觉事实，
`mock_protocol` 和纯展示保留未读。已有机器转写可被检索，其出处注明为增强文字。
能力失效、失败、取消和未读各有轨迹。部分读取只能支持实际摘录或读到的内容。

每一轮的引用由本消息的 `evidence_id` 解析。生成或展示时若只拿到 C 找出的父页/同 Cell 邻接，
不可据此宣称子对象已读。D 回退父页时消息块锚定实际 `display_source`，继续保留原请求对象及原因。
E 持久化展示块和证据字典，F 的检索结果单独保留候选轨迹、支持映射与缺项。两部均可通过单独的
公开样例重放。

## 版本与范围

1. 首次检索固定授权课程与已解析文档、每文档可见版及代次。候选只来自 C 的同事务快照。
2. 新查及追加读证据必须由 B 核对实际范围、当前版、原件哈希和代次；D 对图像再核对展示和实际读取。
3. F 补查最多一次，限定在已读定义锚点的课程和该课程内首跳解析的文件子集。补查候选逐项核对首跳版本；
   交付前再复核全量首跳快照。版本或代次变化时丢弃本轮证据并报告失效。
4. E 历史原件只从已有授权消息按 `message_id + display_id` 解析。以保存的版本构造 D 内部 grant；
   已删或跨会话返回同样的不可访问。显示返回前复查权限，换新资料只有明确请求才改变历史焦点。
5. 索引或模型不可用时保留可用信息及缺项。答案只能引用本轮证据字典已有且读到的内容，
   追问的历史文本不作事实证据。

## 可独立运行的交接样例

`course_id=signals` 的可见讲义 `public-lecture` 在 `v1/page:1` 定义去抖窗口，
实验 `public-lab` 在 `v2/cell:3` 保存同一实验名称与观测值。以下为字段示例，ID 和哈希由实际发布返回。

| 步骤 | 为 E/F 提供的数据 |
| --- | --- |
| C 命中讲义页 | `source=public-lecture/1/page:1`，记录实际范围和快照；候选未读。 |
| B 重读对应页 | `evidence_id=ev-1`，`method=native_text`，`actual_source=public-lecture/1/page:1`，原文含实验记号 `WindowSweep7`。 |
| F 补查实验 | 仅用上述原文字面 `WindowSweep7`，第二跳沿同一解析后的范围，读回本轮 `ev-2`，支持实验事实。未满足时保留缺项。 |
| E 显示实验图 | D 输出的实际来源绑定消息内显示块，分别保存 `display_id` 与 `evidence_id`。用户点卡或在该完成消息后只输入“刚才第二张图”，后端从该消息的实际可见图片顺序解析。 |

E02/F02 合入后，以各自测试对空课程、错误代次、未读与模拟视觉、结果/原件回退及跨课越权
核对这份数据面。模型回答中的引用保持在本轮范围内。
