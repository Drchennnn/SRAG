## 运行方式与授权

E 的浏览器页面和业务 API 同源，本地服务默认绑定 loopback。受信任配置限定可访问课程。
允许的课程来自服务端设置；创建会话的 `course_ids`、切换课程和文件都只在授权集合内选。
未经允许的输入直接拒绝，不静默扩大、缩小后继续查别的资料。浏览器通过随机、HttpOnly、
SameSite=Strict 的所有者凭据恢复本机的会话列表。同一浏览器可有多个会话，各自持久化
范围和焦点；独立浏览器配置使用不同所有者。服务端只保存凭据摘要，`session_id` 本身
没有授权效力。变更与导入路由校验同源，终端用本地 owner capability 调用同一 service。
首次同源 `POST /sessions` 在既无 owner cookie 也无 owner capability 时，服务校验请求后
生成新的不可预测 owner 凭据、摘要和随机会话 ID，在一个事务新建会话，成功响应才通过
`Set-Cookie` 发放凭据。该路径不接收客户端指定 owner 或会话 ID。已有合法凭据时
在其所有者下新建会话。显式携带无效、格式错误或过期的凭据时，返回 `404/not_accessible`
且可清除前端过期 cookie，后续由新的无凭据请求显式初始化，不继承旧会话或接管任何所有者。
读取、继续已有会话与媒体操作中的无凭据、跨所有者、跨会话引用和超出课程授权统一
返回 `404/not_accessible`，不暴露对象是否存在。

区分两个范围。会话的当前检索范围可由用户显式修改，固定一轮中解析出的文档集合，
当轮将该范围和版本记录送入 `TurnScope`。历史授权由所属消息已经绑定的资料、
当前的服务端课程权限以及 B 对精确版本的校验共同决定。切换文件会重置当前定位，
允许查看仍获准的历史媒体；按历史卡片继续提问时若卡片不在现行检索范围内，询问
是否切到该文件。删除资料或撤回课程权限后，同一历史链接也不得得到内容和元数据。

存储的历史快照仅供服务端解析。每次读取会话、单轮、重复请求结果或媒体时，重新
检查存储中所有依赖来源的实时授权，包括候选或解析轨迹中未进入最终证据的来源。
无权项的版本信息、位置、引文、候选与匹配原因、解析轨迹、媒体 URL 和读取结果
均从输出移除。引用该项的文本块、答案依据、摘要及派生选项也整体替换成失效通知，
混合多源而无法分离依赖的块按整块处理。持久内部索引保留顺序以避免其余图自动改号，
对外仅给通用失效占位，不释放失效节点、证据或媒体标识。重放已完成请求遵循同样的脱敏。
E02 测试同时检查会话快照、单轮回放、澄清选项与直连历史媒体，不仅检查图片下载。

## 持久化与生命周期

E 对同一个 B SQLite 文件作增量建表，外键与写事务保持一致。E 不复制 B 的原件目录。
以下列名给出需保存的数据，允许用 JSON 保存单条结构化值。

| 表 | 主键、关键字段及不变量 |
| --- | --- |
| `workspace_sessions` | `session_id`，`owner_digest`、标题、授权范围选择、显式 `course_ids/document_ids`、`scope_revision`、`focus`、时间。焦点只指向本会话刚验证的目录节点或消息显示引用；切范围递增修订并清除旧的当前焦点。 |
| `workspace_turns` | `turn_id`，唯一 `(session_id, client_turn_id)`，规范请求指纹、快照、状态、attempt token、租约截止、错误或澄清类型、显示解析轨迹、时间。终态的同 key 请求返回同一轮。 |
| `workspace_messages` | `message_id`，唯一 `(session_id, ordinal)`，轮次、角色、块序、`sources`、冻结的 `visible_display_ids`。用户消息在轮次预约时写入，可引用助手消息只在完整提交后可用。 |
| `workspace_media` | 唯一 `(message_id, display_id)`，`session_id/evidence_id`、原请求 `SourceRevision`、`display_source`、渲染规格、D 实际区域、MIME、尺寸、SHA 与已核验图像字节或同 SHA 的内部缓存引用。显示身份分开，相同字节可共用。 |

轮次状态为 `running → completed | clarification | failed | cancelled`。`completed`
在同事务写成有序块、证据字典、媒体和显示索引。原生读取和真实视觉记录用共享
`TurnEvidence`，派生文字保留出处，浏览专用图片可有 `not_attempted` 记录。
刷新、重复请求或网络中断查询都读取持久快照。运行中再次以同 key 请求得到
`202` 和同一轮 ID，完成后再次获取会得到同一消息；同 key 不同内容为
`409/idempotency_conflict`。不同会话可并行，同一会话同时只预约一条进行中的轮次。
状态比较与轮次预约使用短事务，C/D 读取与外部调用在事务外进行。

取消由所属会话发送 `POST /turns/{client_turn_id}/cancel`，以状态和 attempt
token 比较交换。取消或超时的结果不能覆盖新的 attempt。已经发出的模型请求可能
返回，晚到结果不进入消息。错误保留可重试标记，用户显式重试使用
`POST /turns/{client_turn_id}/retry`，沿用原 payload，换 attempt，不增加该轮用户消息。
正常重复提交不会触发重试。客户端断连后轮次可继续，在已知 URL 查询；运行租约
到期后置为 `failed/interrupted`，允许重试。首版普通 HTTP 响应加快照查询，不要求 SSE。
模型服务或解析异常保留可回到目录的页面，用户可主动取消或重试，并能浏览与读图无关的原件。

快照不能在执行中被混用。轮次取 C 的固定发布列表，所有引用先以 B 的课程、当前版、
原件哈希与发布代次逐项复查。D 视觉读回后复查实际来源。最终落盘在同一 SQLite 写事务
复核活授权、`scope_revision` 和固定快照中实际使用的文档。通过 B 的
`promote_due(db, cutoff)` 与已签字段作同事务读校验，B 仍拥有候选版本更新。
发现改版或取消时丢弃待提交证据，返回明确 `stale_reference` 或 `cancelled`，
提供显式重查入口，不拼接两个代次。摘要限制在用户选定的一份当前资料，
按实际检查范围标识部分总结，避免把散落候选冒充通读。

## 消息块和两种追问

有序块用数组保存，`type` 为 `text`、`source_image` 或 `notice`。文字块的
`citations` 只引用本消息存在并读到相关内容的 `evidence_id`。图片块含
`display_id`、`evidence_id`、实际 `display_source`、`rendition_kind`、媒体 URL、
标签、尺寸及必要的坐标信息。每个 `display_id` 仅在该消息内唯一；同一图显示两次
有两个 `display_id`。原请求来源和实际读取来源保存在本消息证据，D 父级回退时，
显示与追问均锚定实际父级，另显示回退原因。模型禁用和加载异常均有明确状态。

`visible_display_ids` 是服务端完成消息时按 `blocks` 出现顺序提取且拥有已验证
可展示媒体的图片块 IDs。文字、目录树图标、澄清缩略图、加载占位、未成功渲染卡
不计入。浏览器严格按同一数组呈现，并标注序号，不依赖 DOM 排序、CSS 位置、
候选排名、用户视窗或出现在另一条消息中的图。刷新后从持久记录重建。历史授权撤回
或渲染资源失效时保留原位置的失效标记，读取时再次核验，避免把旧序号迁移到另一张图。

1. **点卡片。** 点消息中的“问这张图”在输入区置可见引用，
   `POST turns` 发送 `anchor={type:"display",message_id,display_id}` 与问题。
   服务在当前 owner/session 中检查消息已完成与显示记录，得到实际 `SourceKey`，
   用户提供的键永不参与定位。矩形及父页绑定也取服务器登记。
2. **自然输入。** 只发送 `text:"刚才第二张图"`，无 `anchor` 和 `source_id`。
   `刚才` 以本会话按持久序号最近的一条已完成、带可见图片的助手消息为锚，
   上一条读图追问、澄清或待处理消息没有新图片时不挤占。将中文序号或阿拉伯数字
   解析为一基序号，对冻结的 `visible_display_ids` 取值。第二张图从来源工作区的
   第二列、Notebook 输出数或同一幅图的子图编号推导均无效。
3. **澄清和失效。** 无指向词的“那张图”在锚消息有多张图时，或回指消息不唯一、
   序号不存在时，给至多若干张已授权的卡片选项或提示补充指代。选项键在同一会话
   对应持久的澄清轮，单纯猜测目标或偷用历史事实均无效。明确选择经授权核对后
   才继续。失效或历史媒体缺失时保留准确状态，不选择别的图来凑序号。

首轮按 C 当前搜索或明确目录位置，从真实原件构造图片块。指定 Notebook Cell 时，
用 B 版内对象按原输出顺序遍历，跳过 stream、无图和失败图片，最多展示可读的前若干图。
实际跟读由 D `process_current` 针对解析的展示对象作问题定向读取，输入字节哈希
记录于 `TurnRead`。若用户只输入“刚才第二张图”，提供定位、可用媒体及实际读到的
内容；无模型时照常定位并展示，清楚标注未读。定向读图输出留在本轮，F 只读共享证据。

历史链接从授权的消息和显示记录构造 D 内部 `HistoricalSourceGrant`，用同一版
`content_sha256` 与实际来源，检查 B 仍保留且有效。缓存原有图片只在授权和原件
完整性通过后返回；重渲染时核对字节 SHA，失配给明确状态。原页查看以同版登记父级
调 D 渲染，浏览器把保存的 `visible_page_norm_v1` 投影到该页宽高做高亮。
跟读落在不再当前的版本时允许查看旧图并提示选择新版，D03 历史路径仅渲染不外发
定向读图。显式从目录选新版后是新轮。当前版本更换不会篡改历史图或沿旧 source_id 猜新图。

## E02/E03 HTTP 接口

页面 `/workspace`，API 前缀 `/api/workspace`。路径 `{s}` 为会话 ID。
同源媒体返回实际栅格 MIME，附 `Cache-Control: private, no-store`。
执行状态、来源、澄清、告警均经同一 JSON 快照契约。E03 可对本表使用局部 fixture，
E04 验收浏览器从真实端点收发。

| 接口 | 最小请求与响应 |
| --- | --- |
| `POST /sessions` · `GET /sessions` | 创建可用的空会话或列出当前 owner 的会话。创建返回 `session_id`、`scope_revision`、空 `messages`。 |
| `GET /sessions/{s}` | 返回 `session_id,scope,scope_revision,focus,turns,messages`。消息按持久序号，块按数组顺序。不可访问消息来源以失效块呈现，关联证据摘要脱敏。 |
| `PATCH /sessions/{s}/scope` | `{course_ids,document_ids,scope_revision}`，服务端校验有效范围，返回新的会话快照。空 `document_ids` 表示在已选课程内暂不限定文件，执行时仍固定实际文档集合。 |
| `GET /sessions/{s}/catalog` | 返回已授权课程、当前资料版本、章/页/Cell/对象树及稳定节点 ID。无可靠章节则列页/Cell。节点含 `parent_id`、同级可用前后节点、定位、`children` 和状态，支持返回上级。目录中的当前源预览使用服务端登记节点，绑定资料版号、原件哈希与发布代次。 |
| `PUT /sessions/{s}/focus` | `{node_id,scope_revision}`。只接受当前目录节点或清空焦点。节点所属资料不在现行检索范围时明确提示切文件。旧目录引用返回 `stale_reference` 或 `404/not_accessible`。 |
| `GET /sessions/{s}/catalog/{node_id}/media` | 已登记目录节点的当前媒体，认证后核对节点绑定的版本、原件哈希和发布代次，再使用 D 规格。旧引用不可成为新版入口。若当前节点无图，可浏览已有位置与可用原生文字。 |
| `POST /sessions/{s}/import?course_id=…&filename=…&document_id=…` | 一次传一个 PDF、PPTX、IPYNB，`Content-Type: application/octet-stream`。可选 `document_id` 表示明确更新本课程指定资料。服务校验课程、文件后缀和总字节上限，受管 course root 下每个请求唯一子目录，安全文件名，流式接收后经 B 导入；返回去除绝对路径的 B 状态、文件名、文档 ID、版本、代次和可搜行数。浏览器多文件逐个提交，逐个显示状态。输入文件名不得决定授权或覆盖既有原件。 |
| `POST /sessions/{s}/turns` | `{client_turn_id,kind:"search"\|"ask"\|"summary",text,anchor?,scope_revision}`。完成时返回 `{turn,message}`；运行中的同请求可返回 `202`。摘要需唯一文件范围。搜索可复用 C 当前范围结果，候选仍标未读。 |
| `GET /sessions/{s}/turns/{client_turn_id}` · `POST …/cancel` · `POST …/retry` | 返回或变更该轮，并遵循幂等和失败约定。取消后返回原已存在用户消息与取消状态。 |
| `GET /sessions/{s}/messages/{message_id}/media/{display_id}?view=inline\|page` | 按历史授权返回登记的原图、裁图或同版整页。页面高亮由消息保留的规范化区域确定。仅接受两种 `view`，不接受来源 ID、文件路径、矩形或任意渲染参数。 |

资料、章节、页、Cell 和对象节点均绑定所属资料的 `document_id/version/content_sha256/publication_epoch`，
对象节点再绑定 `source_id`。课程容器只负责展开，不可作为对象媒体或精确焦点授权。
`node_id` 是由服务端登记的会话内不透明标识，按绑定的定位和发布快照创建。服务从当前
授权树匹配并核对绑定，无权项统一 `404/not_accessible`。旧 v1 节点在 v2 发布后失效，
同字节重新发布导致代次递增时同样失效；焦点设置、目录媒体和依赖焦点的问答均不从旧标识
解析为新版。E02 测试分别对换版与同字节重新发布验证该行为。

浏览器导入由 E 在 B 的根下持有独占暂存目录，成功归档后删除暂存请求目录；
原件保存在 B 版本记录。明确换版必须验证已有资料属于所选课程，保留 B 的
`document_id`。本轮同文件默认是新导入动作，文件名重复时展示目录中的区分项，
不将同名自动当换版。请求体字节上限由服务端固定，拒绝目录穿越、空文件及不支持后缀。
错误响应覆盖 `404/not_accessible`、`409/idempotency_conflict`、
`409/scope_changed`、`413/file_too_large`、`422/invalid_request`；资源允许但原件缺失
时显式显示 `original_unavailable`。显示块只含会话作用域媒体 URL，快照和模型 prompt
均不传本机绝对路径或夹带其他轮次的私有原文。

以下两个请求独立发起，ID 为示意值。浏览器实际从上一条消息的块索引生成第一种锚，
第二种只发送用户文本和轮次元数据。

```json
{"client_turn_id":"t-click","scope_revision":2,"kind":"ask","text":"横轴单位？","anchor":{"type":"display","message_id":"m17","display_id":"d2"}}
```

```json
{"client_turn_id":"t-ordinal","scope_revision":2,"kind":"ask","text":"刚才第二张图"}
```

若 `m17.blocks` 依序为文字、`d1`、失败卡、`d2`，完成记录为
`visible_display_ids=["d1","d2"]`，两请求均在服务端解析出 `d2`。
第一种轨迹 `resolution=display_anchor`，第二种 `resolution=visible_ordinal`，
记录 `message_id, display_id, ordinal, actual_source`。澄清响应为
`{turn:{status:"clarification"},message:{blocks:[…]},options:[{option_id,label,…}]}`；
重发按 `anchor:{type:"clarification",turn_id,option_id}` 保存用户选择。
语料读取、可见性变化和模型结果都记录到 `turns` 和本轮证据，页面可重放。
