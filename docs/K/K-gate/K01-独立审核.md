  ```python
  if strategy in {"fts", "s0", "bilingual"}:
      pool = _prioritize_continuations(
          pool, snapshot_sources=scope.sources, docs=scope.docs
      )
      return finish(pool)

  # S3: Optional vector retrieval (text semantic supplement + visual page recall).
  if strategy == "vector" or (
      settings.workspace_vector_retrieval_enabled and vector_bridge is not None
  ):
  ```

  - 对照既有验证代码（`tests/test_j02_multifile_retrieval.py#L710-L711` 及 `docs/J/J02-dev-eval/run_j02_paired_eval.py#L384-L387`），开启 `S3` 必须**同时设置 `WORKSPACE_RETRIEVAL_STRATEGY=vector`**（连同 `WORKSPACE_VECTOR_RETRIEVAL_ENABLED=true`、`QDRANT_LOCAL_PATH=...`、`SOURCE_VISION_ENABLED=true`）。

### 阻塞项 2：多处接口响应字段、状态码与 SQLite 联表断言与真实实现不符

- **设计位置**：`docs/K/K01-发布验收设计.md` 第 84 行（`G2`）、第 100 行（`C2-04`）、第 265–267 行（`C7-01`、`C7-02`、`C7-03`）。
