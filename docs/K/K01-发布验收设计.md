### 9.2 已知限制与未验证边界（须在交付包与 K02/K03 报告如实披露）

1. **`S1`（Jev）本版保持关闭**：48 KB 分批修复已解决 `input_limit` 截断，但远端服务延迟（`p95` 增量 `+34.71s > +8s`）与低置信回退（`21.4% > 20%`）未达启用门槛；
2. **`S3` 与 `H` 问答一跳保持默认关闭的显式可选定位**：`S3` 需配置本地 Qdrant 目录与 DashScope Embedding/Visual Embedding；`H` 问答一跳在固定 `budget=6` 槽位下对纯参考文献/背景题存在轻微槽位挤占权衡；
3. **扫描 PDF 默认不自动后台触发 OCR**：基础导入零阻塞先发布原生结构，纯扫描页需显式运行 `python -m tools.workspace_reading ocr` 增强（或依赖本地 Docling 环境）；
4. **PDF 复杂对象定位保守策略**：无框或重叠透明遮罩图形、复杂跨行合并单元格三线表在无法确认精确坐标时保守回退父页整页（`parent_page_fallback`）与原生读取，避免错框误导；
5. **模型与解析外传依赖**：在线中文综合回答与定向读图分别依赖配置的 DeepSeek 与 DashScope 服务；无密钥或服务不可用时自动退回离线原文摘录与原件浏览；
6. **保留在需求池、本版未覆盖与未验证的能力**：桌面端安装包、本地文件夹自动监听、MCP / Skill 接入、完整检索轨迹可视化界面均不在 M4 交付范围内，不宣称已验证或可用。

### 9.3 验证结论分层与 K02 / K03 交接协议

为严守项目实事求是原则，所有后续报告必须按以下四栏严格分列结论，严禁以自动化或 AI 初评替代人工核对：

- **AI 初评（辅助）**：按四维评分模板对封存输出做逐题预筛与机器统计（仅作辅助初评，需标注未经人工核对之分项）；
