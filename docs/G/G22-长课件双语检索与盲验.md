## 0. 一条真实网页问答示例：以前漏在哪、新版找到哪页、用了什么证据、点引用看到什么

以真实 Chromium `/workspace/`（空库进口、默认开启回答/视觉与 `workspace_retrieval_strategy="fts"`、`workspace_input_token_limit=32,768`）对从未参与过 SRAG 开发的 26 页英文课件 [QLoRA-2305.14314v1.pdf](./G22-fixtures/QLoRA-2305.14314v1.pdf)（87,760 字符，单窗顺序仅能读前 7 页 + 第 8 页前 101 字符）发起的纯自然中文提问 **`Q01`** 为例：

> **用户提问**：`作者在后文实验配置细节中，对不同参数规模模型的随机失活比例分别设为多少？微调时采用了哪种学习率调度策略，以及优化器二阶矩系数、最大梯度范数和按长度分组批处理各自是怎么设置的？`

1. **旧版（`eba76b4` 基线）漏在何处？**
   - 提问全为自然中文，零英文词面。`SQLite FTS5 unicode61` 查不到任何词元，返回 `search_status="no_text_anchor"`，退回页序浏览 `page:1..12`。
   - `read_window` 只读入 **`page:1` 至 `page:7`**（距第 23 页 Appendix B.2 相差 16 页），最终回答只能声明：“已读证据仅覆盖第1至7页，未包含后文实验配置细节，无法确认……”（引用 `ev-1`..`ev-7` 全部指向前 7 页）。
2. **新版找到哪一页？**
   - `_plan_search` 在预算充足（> `fixed_reserve + min_source_bytes`）、单文件超过完整阅读预算、且“中文提问 + 英文为主文档”成立时，对默认 `fts` **按需触发** `bilingual` 检索。
   - `BilingualRewriter` 将问题译为保留语义条件的英文查询（`dropout ratios ... different parameter scales ... learning rate scheduling strategy ... second-moment coefficient, maximum gradient norm, and length-grouped batching`）；英文停用词过滤后 FTS 检出并按文本与空白图像分离记账保留 **`page:23` 排入候选第 3 位**（位于 `page:22`, `page:21` 之后），`read_window` 按相关性优先级装入第 22–23 页（跳过占满窗口的前序无关页）。
3. **新版回答用了什么证据？点引用看到了什么？**
   - 回答准确写出：**LoRA dropout 对不超过 13B 的模型设为 `0.1`、对 33B 和 65B 模型设为 `0.05`；在基准测试线性与余弦调度后选用恒定学习率调度（`constant learning rate schedule`）；`Adam beta2 = 0.999`、`max grad norm = 0.3`；采用按长度分组（`group-by-length`）批处理并指出会产生振荡的损失曲线**（总耗时 `6,144.3 ms`，检索 1 次改写 + 生成 1 次模型调用）。
   - 在真实浏览器里点击回答中的引用 `ev-8`，右侧 `#reader` 原件抽屉正常弹出，精确打开 **`QLoRA-2305.14314v1.pdf · v1 · 第 23 页`（`当前版本`）** 并高亮对应 Appendix B.2 原文段落（同样在 `g22_gate` 完全未见 33 页 `ReAct-2210.03629v3.pdf` 的 `H_Q01` 上，旧版在页序截断中仅读 `page:15[0:963]` 失败，新版将 `page:15` 排第 5 并完整实读 `page:15[0:3804]`，点引用精确打开 `ReAct-2210.03629v3.pdf · v1 · 第 15 页`）。

## 2. 第 2 步：双语检索、池化与阅读顺序修复（零硬编码）

1. **按需触发与预算守卫（`app/rag/workspace.py`）**：
   - 在 `workspace_retrieval_strategy == "fts"`、`workspace_answer_enabled=True`、无显式 `location` 时，`self._plan_search` 先核对预算是否能容纳固定消息包装与至少 1 条证据最小元数据（避免 `fixed_overhead_exceeded` / `no_evidence_fits` 触发无意义外部调用），再对单文件检查 `full_text_scope` 估算：短文件若能整份放入 `budget`，直接跳过检索并完整阅读。
   - 仅当提问含中文字符（`_HAN_QUERY`）且选定范围存在“拉丁字母数 > 汉字数”的英文为主文档（`_has_latin_corpus`，避免含少量 `Softmax`/`TopK` 等代码词的中文笔记误触发）时，按需将本次检索切换为 `bilingual` 并传递 `candidate_budget = request.top_k (12)`。
2. **改写约束对称性与英文停用词（`app/clients/deepseek.py` · `app/rag/structure_search.py` · `app/rag/workspace_retrieval.py`）**：
   - 修复 `_NEGATION` 中 `"非常"`（修正为 `"非(?!常)"`）与 `"不同"`（剔除 `不(?:...|同)` 中性的 `"不同/different"`）误把普通形容词当逻辑否定而拒绝合法英文译文的缺陷。
   - 修正 `_valid_rewrite` 中 `_LITERAL`：当目标语为 `"English"` 且引号内为中文短语（如 `“只训练回复部分”`）时，不再强求译文原字保留中文字符，而是校验其中嵌入的 ASCII/数字词元（如 `“MMLU 基准”` 须保留 `MMLU`）。
   - 在 `StructureSearcher._query_plan` 对 `OR` 查询过滤常见英文高频功能词（`_EN_STOPWORDS`），保留实义词进入 BM25；当存在非停用词时避免虚词拉高泛化页分值。
3. **文本与视觉分离记账，保护高排名邻接continuation（`app/rag/structure_search.py` · `app/rag/workspace_retrieval.py` · `app/rag/workspace_reading.py` · `app/rag/workspace.py`）**：
   - `_select_with_reserved_edges` 对邻接边按 `(空 text 的 child_object 置后, 种子排名, 边类型优先级)` 排序，使高排名 FTS 命中的 `next_position` / `previous_position` / `parent_context` 邻接页不被低排名的空文本图像占用保留槽。
   - `plan_retrieval` 与 `_fuse` 将有文字候选（`selected`）与无文字图像候选（`visual_candidates`）分开记账，`visual_candidates` 在 `_generate_snapshot` 透传至 `_media_candidates`，既不挤占 12 个文本位，又保留视觉邻接附件；`_prioritize_continuations` 将前 2 名高分锚点已在池内的直连后继页紧跟其后，使跨页附录实验与表格在 32 KB 预算内成对入选。
   - `read_window` 在 `prioritized=True` 时通过 `_group_key` 与 `_preferred_group_ranks` 按 `preferred_sources` 排名顺序装入段落（同父页分组并保留文档内平局排序），确保高相关度后段页（如 `page:20`/`page:23`）不会被前序页面耗尽预算。
4. **控制组与回退实证（`G22-开发对照实测.json` 与单元测试）**：
   - 短文件控制（`Northpoint` 8 页 PDF）：`full_text_scope=True`，0 次改写外调，`2,165.9 ms` 答全 3 轮时间与签核日。
   - 显式位置直读（`DPO page:20`、`QLoRA page:15`、`ReAct page:8`）：`retrieval=None` 0 次改写外调直接读目标页。
   - 视觉对象路由（Notebook `cell:0`）：正常返回 `'Expert ID [index]'`（`1,172.3 ms`）。
   - 改写服务 503 回退（`rewrite_fallback`）：`BilingualRewriter` 记录 `provider_error` 并安全降级至 `fts`，不崩溃、不编造。
