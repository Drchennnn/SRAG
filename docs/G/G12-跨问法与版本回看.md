G10 表明首问偏差来自对象登记或定向词面，表格定向缺口发生在消息组装。G11 已覆盖这些环节，G12 的公开新措辞和换版验证也符合预期。本项只增加验收证据。轻量模型意图解析和证据合成改动不进入本轮候选。公开开发样例只说明修复在这一套资料上有效，换资料收益在候选固定后由独立审核判断。

独立审核者 `g10_gate` 在两份隔离检出使用同一问法摘要，分别以 Chromium 重放，两次退出 0。正式与口语同一对象、否定无读取、双图不猜、列与表同源，以及两条版本引用均签认。[独立实测](./G12-公开对照.json)

两版真实外部视觉调用、视觉缓存复用和失败均为 0，供应商耗时无观测值。G11 三个 PDF 普通问题从调用内部视觉流程到返回关停状态为 4.56–5.65 ms，图片实读状态 `not_attempted`。表格和 Notebook 双版读数是原生内容。真实模型验收由 G13 在封存的第二套资料运行。

## 复现

将 G10 两个公开脚本放到待对照的干净检出。G11 已包含这两个脚本。每次另建空目录，各用一个浏览器进程端口。`G10_QUESTIONS` 使用本页的 JSON 绝对路径。

```sh
G10_SUBJECT="$(git rev-parse HEAD)" G10_QUESTIONS=/path/to/G12-公开问法.json \
  G10_SOFFICE=/path/to/soffice SRAG_PYTHON=/path/to/venv/bin/python \
  bash docs/G/G10-browser.sh
```
