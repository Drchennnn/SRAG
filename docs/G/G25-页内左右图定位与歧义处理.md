## 2. 设计与实现说明

在 [app/rag/workspace_objects.py](../../app/rag/workspace_objects.py) 中按**同页候选分组、可见裁区（优先 `region_rects` 再回退可靠 `bbox`）、方向对称投影与重叠歧义检测**完成通用几何选择，不使用任何页码、文件名或原题坐标特判：

1. **上下方位意图补齐（`object_intent`）**：
   - 在 `_DIRECTIONS` 为 `top` / `bottom` 增加中文自然表达（`上图` / `下图` / `上边` / `下边` / `顶部` / `底部`），同时保留对历史消息指代（`"上面的第二张图"`）、`"上一张"` / `"下一张"`、`"上下文"`、`"如下图"` / `"如上图"` 与复合斜角（`"右上图"` 保持 `unresolved=True`）的安全边界。
2. **同页候选分组与镜像对称投影（`_page_group_key`, `_project_for_direction`）**：
   - 按 `(document_id, version, group_id)` 将同页候选分组（同页多图、多页同名场景互不干扰）。
   - 将四方向（`left`/`right`/`top`/`bottom`）统一映射到标准化区间 `[a0, a1] x [b0, b1]`，使 `[0.5, 1.0]` 始终代表目标方位半区，保证左右、上下严格对称。
3. **方位资格与同页相对位置判据（`_on_side`, `_select_group_direction`）**：
   - 同页有多个已定位候选时：若完全位于目标半区（`a0 >= 0.5`），或主体在目标半区且容忍标签跨中线（中心 `>= 0.55` 且目标半区占比 `>= 0.65`），计入入选集。
   - 同页仅有一张已定位候选时（`single=True`）：若 `a0 >= 0.5` 或（`center >= 0.58` 且目标半区占比 `>= 0.75` 且 `a0 >= 0.40`）才视为确属该方位；单张居中图（如 `[0.20, 0.28, 0.80, 0.68]`，中心 `0.50`、占比 `50%`）在问及左右/上下时返回空集触发询问，不盲猜读取。
4. **明显重叠与未定位竞争歧义（`_overlap_metrics`）**：
   - 若入选对象与同页其他已定位候选存在明显二维重叠（交集面积占较小框面积 `>= 0.20`，如交叉图或嵌套插图），或入选对象本身跨中线（`a0 < 0.5`）且沿目标轴向与同页候选投影重叠 `>= 0.30`，将竞争候选一并保留，触发 `object_ambiguous` 询问用户。
   - 同页存在不可定位兄弟对象（`rect is None`）时仍保留竞争歧义。

## 5. 单独记录的解析/环境限制（不在本项修改范围）

1. **PDF 重叠光栅解析限制**：[app/rag/parsers/local_slides.py](../../app/rag/parsers/local_slides.py#L169-L172) 对同页任意存在矩形交叠的 PDF 光栅对象直接返回 `[]`（整页不登记为 `page_object`）。因此 PDF 原生解析不会产成重叠的 `page_object` 图像候选；明显重叠候选主要通过 PPTX 原生 shape（`SensorLab-Overlap-CCBY4.pptx`）及 `RegisteredRegion`（`region_rects`）两条已登记路径实证。
2. **PDF 矢量图与无竖线三线表**：与 G20 记录一致，`local_slides.py` 仅登记顶层无透明/无嵌套 Form 的独立光栅图与闭合轴对齐格线表；无竖线 LaTeX 三线表（如 `Mixtral` Table 1–5）及纯矢量插图未登记为 `page_object`。
3. **本机 LibreOffice 缺失**：执行机未安装 `soffice`，因此 PPTX 整页/裁图渲染测试跳过（3 skipped）；PPTX 重叠对象选择与 `object_ambiguous` 判别在入库后不依赖渲染器，已在真实网页正常验证。
4. **单页跨中线极端比例**：当跨中线标签使单张图宽跨过中线且主体占比低于 `65%`（或双图交叠超过 `20%`）时，算法会保守退回询问用户而非强制猜选；斜角复合方位（如“右上图”）保持 `unresolved=True`。
