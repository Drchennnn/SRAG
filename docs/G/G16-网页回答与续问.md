# G16 网页回答与续问

工作区在 `WORKSPACE_ANSWER_ENABLED=true` 且配置 DeepSeek Key 时，对普通问答和单文件总结启用生成。现有定向查图、原生表格与跨类证据仍可各自核验。模型收到用户原问、必要上下文、本轮实读文字、来源键与位置。服务端只接受指向本轮实读来源的引用 ID。提取、显示和模型实际读取分别记账。配置关闭或模型无法生成有效答案时，页面将原生结果标为摘录。

## 范围与续问

- 正在浏览某页时，问这一页只读页内范围。明确说整份课件时，按文档范围读。适合在预算内读完的英文课件把前后页一道给模型。较长时使用 G15 优先来源与续读游标。
- 短述前一答时复核前一轮实际引用的原文。普通会话、其他所有者、资料换版或手动切换的范围仍受现有约束。用户明确转问授权课程的另一文件后，追问可在未发生手动范围变化时延续该文件。否定文件或名称无法确认的请求不发送其他资料。
- “刚才第二张图”沿原有可见顺序。简短换版追问可按相同对象位置匹配历史和当前各自原件。匹配不到时请用户明确文件或对象。读到双版证据时，比较以事实所属的版本角色与各自可开引用为准。
