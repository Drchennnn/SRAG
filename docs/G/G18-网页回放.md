# G18 网页回放

产品候选 `c3c47eb951ed61dd107cf9dfa6bb82efcf9d7c50`。每次回放用 Git archive 启动候选提交的 FastAPI 工作区，以空 SQLite 和资料目录为起点。导入 G16 公开八页 PDF 的两个版本、G10 公开单页表格 PPTX 和含保存输出的 Notebook。浏览器使用普通发问、目录、引用和文件操作按钮。

## 接口与状态

- 聊天输入框留一个「发送」，以原有 `kind=ask` 提交。文件区的「总结此文件」用 `kind=summary`，资料库「查找原文」用 `kind=search`。快捷操作保留聊天草稿，不影响下次发送。
- 点目录条目、文字引用或已显示图像可开原件。宽窗口为独立侧栏，窄窗口为抽屉，可用 Escape 或按钮关闭。打开抽屉时保留聊天滚动位置。
- 文字引用仍使用旧原文接口授权。新增的 `.../evidence/{evidence_id}/preview` 按引用绑定的版本返还原页或保存输出。原件失效时保留返回的已提取文字和可理解的错误反馈。
- 直接读图引用打开该消息的同一显示对象。对只有视觉引用的追问，服务端校验相同会话、已完成且仍可访问的引用、历史显示记录和读图输入摘要，然后复用该附件的原字节。展开裁区所在整页时，侧栏会提示实际读图范围为裁区。
- 目录预览只展示，不触发模型。网页明确区分已提取文字、已将文字交给回答模型、图像未读、读图成功和缓存复用。

## 回放方式

```bash
cd /Users/Link/code/SRAG
G18_SOFFICE="$(command -v soffice)" bash docs/G/G18-browser.sh
G18_PORT=19158 G18_NO_RENDERER=true bash docs/G/G18-browser.sh
SRAG_SOFFICE="$(command -v soffice)" .venv/bin/python -m pytest -q tests/test_workspace_preview.py
```

`G18_SOFFICE` 与单测的 `SRAG_SOFFICE` 可传 LibreOffice 应用包的 `Contents/MacOS/soffice` 或可用的可执行文件路径。第二个回放模拟找不到渲染器，只修改该服务进程内的函数。回放默认使用当前 Git 提交，可用 `G18_SUBJECT` 指向本机可访问的候选提交。脚本结束时打印独立目录中的证据路径。可用 `G18_OUT` 指定一个新的输出目录，或用 `SRAG_PYTHON` 指定已有依赖的 Python。

回放拦截外发 HTTP，关闭真实回答服务。问答因此采用明示的摘录回退。Notebook 视觉追问在服务边界回放一次合成答复，正常产品路径随后返还绑定的原图。合成答复不计真实读图或真实调用。G16 的真实回答实测见 [G16 网页验证](./G16-browser-validation.md)。

## 实测

Chromium 157 在两个空库各通过 8 轮网页操作。每次回放有 4 次导入，PPTX 与 Notebook 各 1 个版本，PDF 两版共享同一 `document_id`。

| 操作 | 实际展示与结果 |
| --- | --- |
| 首问与纯文字追问 | 从 PDF 第 5 页问签字截止，随后输入「用一句话概括刚才的回答」。两轮都有 `August 23` 的第 5 页引用和离线摘录提示。 |
| 单次文件和资料库操作 | 请求依次为 `ask, ask, summary, search, ask, search, ask, ask`。总结和查找都保留未发的聊天草稿。 |
| PDF 原页与窄窗口 | 目录和文字引用均打开 PDF v1 第 5 页，1300 × 880。1440 × 900 为侧栏，680 × 700 为宽 490 px 的抽屉。打开抽屉前后聊天位置均为 955 px，无横向溢出。 |
| 刷新与换版 | 先打开 v1 引用，再发布 v2 并刷新网页。原消息恢复，旧引用显示「历史版本」，仍返回 `version=1, source_id=page:5`，渲染摘要前后一致。 |
| PPTX 整页与裁区 | LibreOffice 返回 v1 第 1 页 1440 × 1080 和目录里的表格裁区 1210 × 332，二者字节摘要不同。搜索 Cedar 的原文引用可打开同一页，文字包含 Frequency [Hz]、Cedar 和读数。 |
| PPTX 无渲染器 | 整页、表格裁区及原文引用均返回 409 并显示渲染回退提示。表头、单位和数据行继续可见。PDF 和 Notebook 原件仍返回 200。 |
| Notebook 输出与点图追问 | 目录打开 v1 的 Cell 1、输出 1，640 × 450，字节与 Notebook 内保存图片一致，状态为「仅展示 · 图像未读取」。点击卡片追问后，离线回放的读图记录绑定同一摘要。回答没有复制图卡，点视觉引用仍回到该输入图片。 |
| 会话隔离 | 在侧栏开着时新建会话，新会话无旧消息和侧栏内容。切回原会话恢复 8 轮消息。 |

初次独立审核发现纯视觉引用只能显示文字标签。复核前补齐了带原图卡的引用和没有复制图卡的点图追问两条打开路径。`g14_gate` 在固定版本从两个空库独立回放并通过，含有真实 LibreOffice 的定向测试 34 项全过。含 G17 的合并验证 519 项通过。浏览器回放全程实际外发调用为 0，未测 VSCode 内嵌浏览器。
