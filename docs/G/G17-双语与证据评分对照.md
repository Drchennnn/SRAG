# G17 双语与证据评分对照

本项只在架构负责人授权的 G17 中接入真实 Jev。以 G16 已发布产品为起点，固定合成公开原件、课程与版本，以及同一个 DeepSeek 回答模型和最终证据预算。用户原问始终保留，改写和评分均不能扩大原问题的课程、文件、位置和版号许可。

| 组别 | 候选和读取 |
| --- | --- |
| A | 现有 FTS 加结构邻接 |
| B | 原问与等义双语改写共同召回，按版本化键合并 |
| C | 用 Jev 评分 B 的相同候选池，根据有效的分数排序 |
| D | 从 C 已验证并读取的文字取字面术语，最多补查一次。新增来源分开记录 |

短选中文档若能读全，工作区可直接走 G15/G16。预算对照的每组只把最终入选并已读取的文字送到同一模型。不论哪组，候选或分数本身都不能为回答中的事实提供依据。图注作为定位线索，只有打开精确对象并核验供应商实际收到的图像，才计入读图。

Jev 对照复用 G14 配置 `JEV_BASE_URL`、`JEV_MODEL` 和 `JEV_API_KEY`。默认工作区策略 `fts`，可通过 `WORKSPACE_RETRIEVAL_STRATEGY` 选择 `bilingual`、`jev` 或 `expanded`。明确页或 Cell 的问题及可完整读取的短文件可直接使用本地证据。超时或无 Key 时保留提供者状态和现有候选，用户可从证据和回答核对缺项。配置生效需重启进程。

公开合成连通探针向真实 `Zev-1` 提交相关事实及同实体干扰项，HTTP 200，得到 0.965193 与 0.00226。同一客户端实例内的原样请求命中缓存，零新增出站。这组只验证评分接口及缓存，效果评价见四组对照。[正反探针](./G17-jev-smoke.py) · [真实回执](./G17-jev-smoke.json)

## 固定快照的真实对照

候选 `8ab177f4af36b12c9d23a2a1b8c18f30c292bd10`，答复与改写均使用 `deepseek-flash`，评分 `Zev-1`，视觉 `qwen3-vl-plus`。四组共享同一份公开 SQLite 及每组最多 4 个最终来源。独立审核逐题确认 B 组和 C 的有序评分输入完全相同。早期五题跑完后增加一条补查正对照；首跑、探针中止和正式结果分别留档。

| 用例 | A | B | C | D |
| --- | --- | --- | --- | --- |
| 纯中文公式与限制 | 无候选 | 读到公式和限制 | 同样读到 | 同样读到 |
| 换一种公式问法 | 缺限制 | 条件在候选中，前四份漏读 | 排进前四并实际读到 | 同样读到 |
| 跨文件原生表与条件 | 单位和条件齐 | 前四份丢了原生表 | 恢复原生表与关联条件 | 拒绝弱新增证据 |
| 缺少相近实验证据 | 明确拒绝外推 | 明确拒绝外推 | 明确拒绝外推 | 明确拒绝外推 |
| 图注、对象与实际读图 | 找到同一右图并实读 | 同源 | 同源 | 同源 |
| 已读题签补查 | 缺结论原件 | 缺结论原件 | 缺结论原件 | 从第 3 页实读 `DXW-63` 字符 264–270 补查新第 9 页，读到 `31 dB` |

原自动判定 A/B/C/D 为 2/3/5/6（各 6 个）。A 的缺证据例被字符串规则错扣，独立读回原句确实拒绝 90% RH 外推，分段审核修正为 **3/3/5/6**。图组四臂通过的是找到图注、精确定位并实际读取，文字答复实验仍只用文字段落，对图片单位明确缺证。完整普通网页的视觉答复另在 G19 验证。补查正对照保留已读锚和预算，记录挤掉的旧候选；其余表格题的弱补查未进入答案。

正式对照运行方的 HTTPS 观察记录 **39 次真实 HTTP 200**，其中 DeepSeek 回答 23、改写 6、Jev 9、图像接口 1。另有一次本地注入的未外发 503，按生产重试路径在真实 Jev 得到 200。Jev 9 次真实响应头耗时中位数 1,856.427 ms，最大 15,449.432 ms；回答模型 23 次中位数 334.555 ms。后续三次同图读回命中视觉缓存。Jev 和改写热命中使用试验共享的客户端实例，普通网页每请求构建实例。向量对照本轮未跑。

这一组结果支持在文字召回明显不足时试双语，在同一候选池的必要条件被预算挤出时试 Jev。补查适用于有实读字面锚且能检验新增来源的情况。短文件优先可追溯读全。六个公开小样本中双语也曾挤掉正确原生表，Jev 增加真实等待，所以默认继续用 `fts`，其他策略保持显式可选。独立审核者 `g14_gate` 在固定版本重跑定向 60 项及真实 Jev 正反探针，主会话跑全量 515 项。

## 复现

从干净检出启动，使用对应发布 SHA 和本机 SRAG 配置。每次分配不存在的 `--out` 目录。

```sh
PYTHONPATH="$PWD" .venv/bin/python docs/G/G17-jev-smoke.py --env-file .env
replay="$(mktemp -d /tmp/srag-g17.XXXXXX)"
PYTHONPATH="$PWD" .venv/bin/python docs/G/G17-probe.py \
  --subject "$(git rev-parse HEAD)" --out "$replay/paired" --env-file .env --retry-probe
```
