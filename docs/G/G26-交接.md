## 2. 实施改动（仅限意图、路由与专属测试）

1. **[app/rag/workspace_objects.py](../../app/rag/workspace_objects.py)**：
   - `_TABLE_NUMBER` 与 `_ordinals` 支持中文 `表 1` / `表1` 序号解析；
   - 收紧 `object_intent` 的表对象触发条件：仅当问法包含显式表序号（`tables`）、方位（`directions`）、表列结构词（`_COLUMN`）、显式表指代（`_EXPLICIT_TABLE_REF`）或显式页/Cell 位置（`_EXPLICIT_LOCATION`）时返回 `ObjectIntent(kind="table")`，使“实测表中”“表格里”等纯事实/比较提问自然回落至普通检索与生成问答；
   - 在有明确表目标的打开/查看指令（如“打开第 4 页的表 1”“查看第 5 页第 1 张表格的原表”“打开那张表”）放行，同时保留“打开原表”“请展示第 2 张图？”的既有边界回归。
2. **[app/rag/workspace.py](../../app/rag/workspace.py)**：
   - 新增 `_TABLE_REFERENCE` 与 `_resolve_table_reference`（`route="followup_table"`）：承接会话上一轮已完成回答中展示/引用的唯一表对象与当前版本，核对范围与版本新鲜度（跨范围提示 `outside_current_scope`、版本变化提示 `historical_only`），事实类追问完整读取原生表格全文送入 `_generate_draft` 回答（修复 900 字预览截断），纯重看指令沿用 `_render_table_crop`；
   - 新增 `_disambiguate_table_choices`：当多张表进入候选时，优先基于题面中的区分性词汇匹配表格及父页正文，唯一命中则直接定位，避免多余澄清；
   - 新增 `_format_table_ambiguity`：确有多个候选表且无法区分时，保留 `object_ambiguous` 块码并在提示文本中列明各候选表的文件名、页码与标题/内容摘要供用户选择。
3. **[tests/test_workspace_table_routing_g26.py](../../tests/test_workspace_table_routing_g26.py)**：覆盖 4 类意图边界、事实问法旁路澄清、明确表打开 + 会话追问以及多表真歧义 vs 可区分/单表直开的单元测试与 HTTP 端到端测试。
