## 2. 确定性数量等价校验设计（只改校验与观测，不改检索路由）

严格遵守 `RAG.md` 边界，仅更新 [workspace_retrieval.py](../../app/rag/workspace_retrieval.py) 与 [test_workspace_retrieval.py](../../tests/test_workspace_retrieval.py)：

1. **观测增强**：`BilingualRewriter.__call__` 在 `constraints_unverified` 分支补充记录 `trace["constraint_reason"]`，区分 `vague_numeral`、`literal_missing`、`negation_missing`、`comparison_mismatch`、`numeric_or_unit_mismatch` 与 `clause_binding_mismatch`，而不改变既有外在接口契约。
2. **精确量值与单位解析（`_validate_rewrite_constraints` / `_valid_rewrite`）**：
   - 使用 `Decimal` 精确表示，覆盖显式中文数词（`零..九/十/百/千/两/点` + `万/亿/兆/万亿` 及混合形式 `540亿`）、英文数字词（`hundred/thousand/million/billion/trillion`）及分数（`千分之一` ↔ `one-thousandth` / `0.001`）、阿拉伯数字及千分位/简写（`540-billion`、`320,000`、`150K`、`60M`、`1.3B`、`2.5T`）和常见单位（`mg`/`g`/`ms`/`us`/`bit`/`%`/`samples|examples` 等）。
   - **安全拒绝模糊数词**：`_VAGUE_NUMERAL` 与 `_VAGUE_ENGLISH` 显式拦截“几亿”“数十万”“约十来个”“上百次”等不可精确等价的约数表达（`vague_numeral`），退回原问 + FTS。
   - **屏蔽中文非数量惯用语**：`_ZH_IDIOMS` 过滤“十分（有限）”“一般”“一致”等含数字符号的非数量固定搭配，避免误拦。
   - **保留比较方向、否定与字面锚点**：`_extract_comparisons` 对齐 `>=` / `<=` / `>` / `<` / `!=` 及中英文自然边界词（并豁免 `under <X> budget` 介词短语与未绑定数值的泛化描述），先剥离“不超过 / 不低于 / 不少于 / no more than / no less than”再检查真实否定丢失；`_LITERAL` 保护 `v2.1`、`top_k=5`、`llama-7b`、`gpt-4` 等版本与代码标识符。
   - **分句对象-数值绑定**：`_extract_clause_bindings` 提取共享锚点与同句伴随数值（并先掩码 `ident=val` 防止二次切分），拦截两个对象互换数值（`7B:64 / 65B:16`）与单侧增删数量，同时允许合法的分句语序重排。
