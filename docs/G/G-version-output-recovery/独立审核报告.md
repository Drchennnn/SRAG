## 6. 审核发现与变化追踪

### 已验证关闭的缺陷（相较 `3e45b24e`）
1. **已关闭（原中级缺陷 1）**：`_IMAGE_REFERENCE` 现已兼容 `"刚才读过的旧版图"`、`"最新版里刚才读过的图"`、`"只看旧版刚才读过的那张图"` 等定语/动词修饰表达，在 `a1`、`a2`、`a4-对照1` 中均准确进入 `_resolve_reference`，不再误落入 FTS `excerpt_fallback`。
2. **已关闭（原中级缺陷 2）**：`b2` 中当用户使用 `"对比最新版和上一版刚才读过的图的纵轴单位和数值"`（不带 `"图片"`、继承前轮 `ordinal=1`）时，`_reordered_comparison_options` 现已正确返回完整候选列表 `['hydro_reorder.ipynb · v2 · 输出 1', 'hydro_reorder.ipynb · v2 · 输出 2']`，不再缩减为单选项。

### 保留的低优先级建议（非阻塞）
1. **【低 / 体验】重排比较澄清选定后的下一轮仅实读 v2 单边对象，且 `answer_current_image` / `compare_versions` 引用的 `/evidence/{eid}/preview` 返回 404**：
   - 在 `b2` 中选择重排澄清选项 `输出 2` 后，`_choose` 路由到 `answer_current_image` 并沿用原比较句 `"对比最新版和上一版..."` 询问 `qwen3-vl-plus`，因该轮只送入 v2 单张图而返回 `status="partial"`（未自动并入 v1 读值形成双边对比）。
   - 同时，`answer_current_image` 与 `compare_versions` 产生的图像可通过 `GET .../messages/{mid}/media/{display_id}` 稳定返回 HTTP 200，但 `GET .../messages/{mid}/evidence/{eid}/preview` 返回 404（仅 `_follow_display` 路径支持 `/preview` HTTP 200）。
