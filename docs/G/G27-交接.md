## 1. 基线复现（`9569912` 上的 `PagedAttention` 第 9 页 Table 1 / H02）

在基线 `956991253221c2fe4fd63284514f6034c72d9d26` 上核查当前生产路径：
1. **能否定位原表**：`parse_local_slides(PagedAttention-2309.06180v1.pdf)` 对第 9 页仅产出 `page:9`（0 个 `page_object` 表格）。`_confirmed_pdf_tables` 硬性要求 `len(horizontal) >= 3 and len(vertical) >= 3` 且交叉形成闭合网格，因此 LaTeX `booktabs` 无竖线三线表全部漏检。
2. **网页接口现象**：在 `WorkspaceService` 中选中第 9 页并提问 H02，路由进入 `target_object` 后 `object_candidates = []`，返回 `object_not_found`（`"找不到能核对位置的指定对象，请补充文件、页或 Cell 及对象位置。"`）。
3. **父页抽出文字与错列原因**：`page:9` 原生线性文本中 Table 1 被抽成无列分隔符的空格串（如 `GPUs A100 4×A100 8×A100-80GB`、`Total GPU memory 40 GB 160 GB 640 GB`）。G20 的隔离探针 `C2a` 回退父页文字时虽答对 `9/12` 项，但因 `GPUs` 行缺乏列分隔符，将 `4×A100` 错配给 `13B`、`8×A100` 错配给 `66B`。

## 2. 技术选型与实现方案（原件坐标 + 水平线 vs Docling）

- **选型对比**：优先评估 `pypdfium2` 原生水平线（`FPDF_PAGEOBJ_PATH`）+ 字符坐标（`get_charbox` + `get_text_bounded`）与已有 Docling。由于 `pypdfium2` 字符坐标直接提供 PDF 原生底左坐标系精确外框（零模型推理开销、零渲染、毫秒级确定性），可直接产出精确 `bbox` / `native_bbox`（供 `object_crop` 裁图与 `#reader` 高亮）并通过垂直空白槽（whitespace gutter）恢复严格列归属，**无需引入重型 Docling 布局推理**。
- **核心机制（[pdf_tables.py](../../app/rag/parsers/pdf_tables.py)）**：
  1. **水平线分组与图表/多栏过滤**：聚合同左右跨度（误差 `<= 5.0 pt`）且至少 3 条、`高度 >= 16 pt` 的水平线组；排除与已确认网格表重叠、内部含竖线（`vertical` 矢量图框/柱状图）或 `>= 5` 条等距网格线（`max_gap / min_gap <= 1.15`）的区域；同时检测并拒绝跨边界截断正文单词的多栏正文区域。
  2. **水平空白槽分列与跨列校验**：在表体多列行上投影短语 `[x0, x1]` 区间并合并间隔 `<= 1.5 pt` 的同列片段，以相邻列中点划分垂直列带；对省略单元格保留空串 `""` 占位，不把右侧值左移到旁列；若多行出现跨列带碰撞（`ambiguous_lines >= 2`）则拒绝登记，保留父页文字回退。
  3. **多行表头与换行单元格**：支持居中跨列组表头（如 `Mixtral` 第 8 页 `First choice` / `First or second choice` 覆盖 `Layer 0 / 15 / 31`）与多行换行表头合并，以及紧邻行距（`<= 1.6 * med_h`）的单列换行续接。
  4. **同字节重导补登记（[local_library.py](../../app/stores/local_library.py)）**：扩展 `_append_missing_pdf_images`，使同字节重导已发布 PDF 时在不修改既有 `page:N` 行、不改写既有 FTS、不升版（保持 `version=1`、仅递增 `publication_epoch`）的前提下补齐缺失的 `page:N:table:K` 对象。

## 5. 已知边界

1. **依赖水平矢量线（`booktabs` 风格）**：当前无竖线表格提取针对含 `>= 3` 条同跨度水平矢量线的 PDF 表格（如 LaTeX `booktabs`）；完全没有任何横线或竖线、纯靠空白排版的表格，以及旋转页面（`page_rotation != 0`）仍保留页级文本回退，不登记为 `page_object` 表格。
2. **极窄列间距与无分隔跨列合并**：若相邻两列之间的水平空白槽小于 `4.2 pt`（或合并列跨越多个列带且在表体出现 `>= 2` 行碰撞），提取器会保守放弃并回退到页级原生文字，避免产生错列表。
3. **非水平线图表与极少数表格误拒**：含内部竖线或 `>= 5` 条等距水平线的矢量图框会被安全过滤；对于 `DPO` 附录 p.22 类跨页长文本对比框等边界版面，若需更复杂版面还原仍需后续按需评估视觉/Docling。
