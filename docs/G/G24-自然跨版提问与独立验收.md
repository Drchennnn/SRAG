## 2. 生产修改说明（严格限于 `app/rag/workspace_versions.py`）

`app/rag/workspace.py` 的共享路由（第 498 行 `if turn.request.kind == "ask" and is_version_comparison(turn.request.text): return compare_versions(...)`）无需改动。仅在 `app/rag/workspace_versions.py` 内完成以下修复：

1. **自然跨版意图识别与四种易混语义精确区分（`is_version_comparison`）**：
   - **支持自然表达比较当前版与上一版**：识别中文自然历史指代（`旧/历史/老/先前/此前/早先/以前/之前/上一/前一/上个/前个/上一个/前一个` + `(?:的|那个?|这个?)?版(?:本)?`）与比较表达（`比较/对比/相比/比对/对照/差异/区别/异同/变化/变动/改动/改变/出入/不同/怎么变了/变了...`、`和/跟/与/同...比`、`比/较 + 旧版/上一版/vN/第N版`），以及英文 `previous/prior/old/earlier version|edition|revision|vN` + 比较词、`和 v1 相比` 类单显式版本号比较、`前后两版/两个版本` 比较，即使未同时写出“新版/当前版”也能路由到 `compare_versions`。
   - **抑制三种假阳性误判**：
     1. **只回看旧版**：缺少有效比较词（含 `"上一版呢？"`、`"之前那版延迟是多少？"`、`"What was in the old version of compare-results.ipynb?"`）返回 `False`；图像追问保留 `historical_only` 路径，不进入 `compare_versions`。
     2. **比较当前版（或单一旧版）里的两张图**：无 `_OLD` 且仅涉及当前版（或单版 `v2`）返回 `False`；同时当无 `_CURRENT`、无对比介词前缀且存在`旧版里/中` + 成对复数对象（`两张图`、`图 1 和图 2`、`two figures`）时返回 `False`，不误入跨版比较。
     3. **提到了“旧版”但没有要求比较**：过滤显式否定比较（`不用和旧版对比`、`不要比较上一版`、`忽略旧版差异`、`Don't compare with the old version` 等，同时保留 `"跟上一版相比，哪些参数没有变化？"`），并在检查 `_COMPARE` 前屏蔽非比较性短语（副词性 `比较重要/关键...`、名词短语 `变化趋势/曲线/规律`、`不同配置/参数/条件/版本/时...`）。
   - **文件名清洗边界修正（`_FILE_TOKEN`）**：确保 `"请比较Harbor-v1.ipynb 上一版和当前版"` 仅剥离 `Harbor-v1.ipynb` 而不吞掉句首 `"请比较"`，同时剥离含 `"compare"` 等词汇的文件名（如 `compare-results.ipynb`）。

2. **自然跨版执行与边界澄清（`compare_versions`）**：
   - **宽松匹配未重设焦点的单文档与隐式多条目组**：当会话范围已唯一锁定单一文档（`snapshot.resolution_status == "resolved"` 且 `len(snapshot.documents) == 1`）时，即使 `session.focus_id` 仍指向换版前的旧节点（`focus is None`），允许继续按范围与历史引用配对；当 `location is None and not image and not intent` 且最近一条已授权助手消息含多个同文档同版本对（如 `cell:0` 与 `cell:0:output:0`）时，统一由 `_compare_native_group` 对两侧版本重读并交由模型综合，不再被死板的 6 字 `_BARE_COMPARISON` 限制在 `comparison_ambiguous`。
   - **范围与版本冲突澄清**：当未指定文件名、无有效 `focus` 且课程范围内文档数不为 1（`len(snapshot.documents) != 1`）时，返回 `comparison_scope` 提示先选定一份可比较资料（若因换版致焦点失效则提示 `"先前定位已随版本变更，请明确要比较的文件及对象。"`）；若仅指定单一版本号且恰与当前发布版本相同（如在 `v2` 上问 `"和 v2 相比有什么变化"`），返回 `comparison_version_mismatch` 而不误取 `v1`。
   - **保留既有安全契约**：完整保留会话隔离（跨会话返回 `comparison_missing_history`）、历史原件哈希校验（缺失/损坏仍返回 409 `original_unavailable`）、已删除文档拦截（`comparison_scope`）及旧图不可复用未核对读图（`historical_image_unread`）。

## 4. 已知限制

1. **只回看旧版的纯文本独立问句**：当用户未使用消息内引用/图像追问、而是直接发新文本问句（例如 `"之前那版第 1 个 Cell 保存输出里的 P95 延迟是多少？"`）时，按当前路由边界不进入 `compare_versions` 且 `_retrieve` 仅搜索当前发布版本（`v2`），回答会诚实报告缺少历史版证据或需要从历史回答中点击引用回看原件；不会凭空跨入未请求的双版比较。
2. **规则意图边界**：`is_version_comparison` 基于确定性正则判别，覆盖主流中英文自然跨版问法与四类易混表达；若出现未收录的极少数口语倒装或隐喻式变化问法（完全不含比较/变化动词且非版本词组合），仍可能落入普通检索。
3. **图像跨版对比旧图复用口径**：保留 D03/G07 现有严格口径，只有历史会话中存在同对象、同输入字节 SHA-256 与同单个属性（如单纯 `横轴单位`）的可信读图时才复用旧图文字；旧图不会在跨版轮次重新发给视觉模型。
