## 失败起点

基线 `82c5a40d3de6224c238ab461bc5d670c5005ba39`。普通网页发送调用 `/api/workspace/sessions/{session_id}/turns`。通用问答进入 `WorkspaceService._retrieve`。`StructureSearcher` 在限定文件无词面命中时可返回 `page_browse_fallback`。`_retrieve` 最多读两个文字来源，各截至 900 字符，并把原生文字写入消息。它未构造 DeepSeek 请求，也未把上一轮话题当成继续检索的输入。选择文件只保证范围，不能使英文摘录成为本题答案。

公开合成英文课件把选项与决定条件分到前、中、后页。独审用正常网页送出中文综合问题，再用中文追问简述。以可打开且包含必要规则的来源、语言与直接答题为本轮口径。现有客户端连接通畅与网页是否使用客户端分别验收。[基线回放](./G14-browser-baseline.json)

两轮均达不到整题通过口径。8 页课件两轮各有 8 个浏览回退候选，实际只读取第 1、2 页，回答文字一致。决定条件位于第 3、5、7、8 页。两次在浏览器点开 v1 第 1 页原文，均为 HTTP 200，视觉状态为未尝试。`g14_gate` 在独立空库重放并核对相同的来源和出站结果。

```sh

```

## Jev 入口

SRAG 的 `/Users/Link/code/SRAG/.env` 支持 `JEV_BASE_URL`（默认 `https://api.zleap.com/v1`）、`JEV_MODEL`（默认 `Zev-1`）和 `JEV_API_KEY`（默认空）。用户在本机填写后重启工作区服务加载。G14 验证配置入口；真实评分属于 G17。

核对本地 SAG-Wiki `92cec195f9262f8506a3ae4b02ddce24b18635ac`，默认 `POST /v1/systemone`，请求以 Bearer 鉴权。`core/src/models.rs` 的 endpoint、评分批次与响应校验对应三个关键点。

- 请求 JSON 包含 `model`、字符串序列化的 `state` 和按候选 ID 编址的 `questions`。
- `state` 保留原问和已检索证据。候选请求 `type=noul`，包含原问题相关性判断、候选标题与原文，以及正反标准。
- `answers` 必须与候选 ID 一一对应。每一项为 `type=noul` 及 `[0,1]` 的数值。SAG 官方 OpenAI `/decisions` 兼容分支不用于 Zleap。

本机 SAG 公开结果中 q0、q2、q3 无候选，公式和图注增词各返回 6 个。公开文件没有原查询和真实读图记录。G17 才在 SRAG 固定证据预算下判断改写、评分、扩展各自的收益。
