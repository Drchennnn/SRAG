# G01 · 日常版联调与验收设计

受测起点为 GitHub main `2b5a12a97c32a08059195eaf32d1974c8babe7dd`。E05 签认持久会话和历史展示，F04 签认在同一证据上限下的一次补查。G02 将二者接到生产网页与工作区服务的同一轮提交，G03 按 A03 封存并评分，G04 在指定公开版本独立重放并核对私有评分汇总。

## 一轮网页提问

1. 用户通过既有 `POST /api/workspace/sessions/{session_id}/turns` 提交普通 `ask`、问题、客户端轮次 ID 和范围修订。服务先处理卡片、澄清选项、图片指代和明确页/Cell。只有同时识别定义和实验两个要求，且没有定向页/Cell 或锚点的普通提问进入 F。文件焦点、显式文件和所选文档仍收窄可查范围。搜索、总结和定向任务沿用原入口。前端无需指定策略或传入来源 ID。
2. E 校验当前 owner、授权课程、选择范围与版本。同名显式文件沿用 E 的选文件澄清，解析为空时显示原有空库或无匹配提示，避免把空列表解释为所有文档。将明确非空的已解析文档与课程交给 F，逐项核对 F 的完整快照与 E 解析后集合中的版本、哈希和代次。F 使用签认的 `EvidenceAnswerer`，最终证据预算为 2。首轮仅有定义时，复用 F 的实验条件判定及已读原文词锚。仅在锚点课的首轮授权文件子集，以原文字面词最多追加一次检索。轨迹记录初始支持与缺项、词锚证据和字符跨度、执行查询与范围、候选拒绝和预算取舍。对照 F04 单跳与补查采用相同 K。真实数据超出 F 的已签原文判定能力时，网页保留已确认项和缺项。
3. E 从已验证的 F 最终事实构造正文、缺项提示、本消息引用和证据字典。去重并以最终被引用的已读证据生成来源控件。当前范围和出版代次在 E 同事务完成轮次时重验。候选淘汰项、截取前的旧版本和读取失败均不得成为答案引用。F 轨迹与本消息绑定，跟随 E 的权限投影；不把被淘汰的原文放进用户可见引用。任何取消、范围失效和换版竞态不得追加半份答案。失效按现有轮次错误协议处理。
4. 文本引用的查看入口以 owner、会话、完成消息及其已保存的证据 ID 查证。页面展示 B 返回的该版本文字、文件名和页/Cell，且显示历史版号；浏览器不拼接当前文档的来源键。引用仅允许本消息正文已用并实际读到的来源。消息返回与查看都做授权复核；已删或越权使用一致的不可访问结果，原件缺失单列。图像、裁区、原页高亮与消息内排序沿用 D/E。用户只输入“刚才第二张图”，服务根据已完成消息的实际可见顺序解析，验收捕获无锚点的实际 POST 和原消息展示对象。
5. 网页只访问同源应用，凭据仅在后端。外部只允许把当前问题及本轮选定的图片送入已配置的视觉服务，旧轮全文、检索摘录、其它图片、答案键和任何密钥不进入请求。纯文字序号的已签流程可用通用图像描述指令，记录实际发送的指令版本。F 按本地原文作答，文字、向量和重排调用为零。用关闭视觉的回放单测退化；真实调用单列，不用模拟或展示缓存代替真实视觉读取。

G03 原始首跑用本机 `data/g-private/` 子目录写一次并建哈希清单，运行角色不覆盖首跑，评分档随后写到独立子目录。发现缺陷后，用另一目录和实际受测修订留复测。G04 核对版本、首跑封存先于评分、各实际分母、失败原因，以及复测是否可和首跑比较。改动后的复测不会替代首跑。公开复现脚本与证据放 `docs/G/`，独立验收报告分别引用公开工件和本机私有根目录，不公布保留题面、答案或可反推答案的轨迹。

## 时延、配置和调用账

- 受测版本记录公开 Git SHA、附加运行器哈希及操作系统、Python、浏览器、LibreOffice 版本、样本字节和页面类型。测试仅从当前任务的公开 Git 归档或待审冻结补丁构建，新建原件、索引及缓存目录。
- 冷导入计为收到新原件请求到同库首次文字查询实际命中的时间，拆出导入和首次查询；热查询用相同库、文件、问题及版本再次执行，另计同内容重导。冷问答指新会话中未建立的目标与空视觉缓存，热问答需指向相同版本、问题、裁区、模型与提示的实际缓存键。说明各轮进程是否重启，操作系统页缓存状态未控制时如实标明。浏览器按提交到答案或可解释错误可见计墙钟，服务内检索、发布、视觉调用另取单调计时。分别记样本量、原始记录、冷/热耗时和可聚合的 p50/p95；无既定延迟通过线。
- 默认真实视觉模型 `qwen3-vl-plus`，实际记录后端读到的模型 ID、供应商类型、提示版本、配置超时与结果；公布有无凭据即可。后端只启用定向图像，关闭外部 embedding、rerank 和文字生成。实际出站尝试含错误与超时，缓存命中另计且出站为零。保留供应商返回的 token usage，未返回的记未知，缺少单价或账单时不估造金额。视觉模型失效后留实际错误和时间，离线复验另记。
- G04 独立审核者从已经回读的受测 SHA 另建数据目录，至少在浏览器走一条正常定义加实验及一条证据不足或故障路径，再复核 G03 的分母和实测条件。表中分别判通过、未达标或未测。可修正缺陷修复后另留复审版本和结果。M2 需通过日常功能及 A03 门槛；未达的结论保留并交架构负责人。H01/J01 待架构负责人放行。
