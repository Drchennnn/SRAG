## 4. 首次断点分布归纳（为步骤 C 定向配对实验提供输入）

在默认网页配置下，17 个必需证据单元中有 **7 个单元通过全链路**（`E06, E08, E12, E13, E15, E16, E17`），**10 个单元在中途丢失**（`E01, E02, E03, E04, E05, E07, E09, E10, E11, E14`）。按每个失败单元**第一次出现断点**的位置归类，全部集中在以下五类具体机制：

1. **读后生成预算预检失配（`E01, E02, E03`，占失败单元 3/10，且同样阻断了 `Q05`）**：
   - `read_window` 按单次 JSON 序列化和 `prompt_reserve = 1800 + ...` 装满 `30,662` 字节，但 `generate_response` 用 `estimate_input_budget(messages) + 128` 对已序列化的 `messages[1]["content"]` 做**第二次 JSON 转义**，凭空多出约 `1,200` 字节反斜杠转义开销（`33,939 > 32,768`），导致凡是读满单窗的 PDF（`Q01`、`Q05`）100% 触发 `budget_exceeded` 退回英文摘录。
2. **长文/跨文件纯中文词法漏召回与候选预算挤出（`E07, E09`，占失败单元 2/10）**：
   - 用户用中文提问英文长文（`Q05` `DPO` 第 20 页）或跨文件提问（`Q06` `DPO` 第 20 页）时，默认 `fts` 无中文命中（或仅命中高频词 `DPO`/`Mixtral` 所在页），`page:20` 未进入 `top_k=12` 候选（Layer 2 断裂）；且在跨文件双语召回下，`page:20` 虽能进 12 候选池（排 #6），又会被 `plan_retrieval(budget=4)` 截断在 Layer 3。
3. **自然问法误入专用死胡同路由（`E10, E11, E14`，占失败单元 3/10）**：
   - `Q07`（`E10, E11`）因自然中文同时出现“定义”与“实验”，被 `asks_for_definition_and_experiment` 劫持到 `SupplementRetriever(top_k=2)` + `^(Definition|定义):` 僵化正则，既把 `E11` 挤出候选，又把已实读的 `E10` 拒答，且全程不调 DeepSeek。
   - `Q09`（`E14`）因自然中文写“跟上一版相比…”而未写冗余的“和新版相比”，被 `is_version_comparison` 漏判，误入只读当前版 v2 的普通检索，丢掉旧版 v1 证据。
4. **PDF 三线表未登记为独立对象且 `target_object` 不回退父页（`E04`，占失败单元 1/10）**：
   - `Q02` 问“第 8 页表格里…”，LaTeX 三线表无竖线故未登记 `page:8:table:1`，而 `_answer_object` 只检索 `object_type=="table"` 且不回退读取已包含完整表格文字的父页 `page:8`。
5. **PDF 双子图方位筛选阈值过严（`E05`，占失败单元 1/10）**：
   - `Q03` 问“第 5 页右侧图…”，`page:5:image:1` 虽已登记（`[0.444992, 0.688088, 0.800889, 0.863947]`，水平中心 `0.623`），但 `_on_side("right")` 硬编码要求左边界 `x0 >= 0.5`，因纵轴标签略微越过中线（`x0=0.444992`）而被直接丢弃。
