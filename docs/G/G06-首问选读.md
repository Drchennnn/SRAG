# G06 · 普通首问选中并读取对象

浏览器的普通问答仍用同一个入口。以公开样例直接输入 `HarborTrace.ipynb Cell 2 第 2 张图的横轴刻度单位是什么？`。从已授权的当前快照先找到文件和 Cell，再按该原件内保存的图片顺序选择。图片顺序包括已声明但损坏的槽位，输出顺序还包括文本流。两种顺序分别解析，不把后一个可读对象顶上来。原生 PPTX/PDF 对象只使用可信几何，颜色或方向本身不足以选择时明确提示。

选中一张图后先渲染核对实际键、裁区和字节。发送前 D 再校验同一字节、同一目标及无父页回退，沿既有模型和缓存。原件卡、实际读取及引用分别保存。原生表格直接读单个对象的文字，零模型调用。关闭视觉时仍展示已知的原件并标为未读，损坏时不展示别的图或给出图像事实。历史点卡及 F 双项问答的优先级保留。

## 公开测量

Chromium 发送的普通首问没有锚或目标 ID。选中的 v1 `cell:1:output:1`、浏览器接收的 PNG 和模型实际输入的 SHA-256 同为 `eb7798a1…371e`，该 Notebook 输出无二次裁图。读出 `seconds`，读取状态 `succeeded`，正文引用同一版本化对象。采集器只允许发送当轮公开问题和该图，实跑一次 HTTP 200。独立空库离线复跑对同图标记 `not_attempted`。另一个普通问题实际读取 `PulseGate-limits.pptx` v1 的 `page:1:shape:2`，引用原生表格里的 `17.5 mA`。

首审补测复现两处问题。文件名材料匹配可能把未知或明确排除的名称误换成已知 Notebook。视觉请求返回过期时，轮次丢失调用计数。现在在选图前核对文件全名和未解析提及，限制打开被排除的对象；读后失效仅保留耗时、状态和调用计数，不写入答案或来源。公开 HTTP 测试也覆盖相似文件名、错误摘要、未知裁区及损坏图片不跳槽。
