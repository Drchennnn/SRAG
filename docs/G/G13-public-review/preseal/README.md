# G13 独立资料与判定

材料来自虚构的信标运维实验课，PDF 含独立嵌入图像、PPTX 含原生表格、Notebook 保留同一未执行 Cell 的两版保存输出。图像的绘制顺序与可见左右顺序相反。文件与预期在候选提交固定前封存，开发只接收摘要和封存 SHA。

组内九次提交都从网页输入框以普通问答发出。八条独立问法加一条同字面热问；热问只作缓存对照，矩阵单列。随答案实际点击内联图片、回原件和文本引用，截图/原件产物存档。测试脚本不填写卡片引用或目标 ID。Notebook 仅上传保存文件，保持同一会话完成换版前后的问答。

评分顺序是正常入口、对象、展示、实际读取、版本、引用、问题结果。候选/选择/实际读取/展示各有独立记录。原件通过上传件 SHA 和页面或 Cell 定位核对。图像核验目标图边界及像素印记并排除邻图。表格核对同一源的读值、列头、单位、裁区、浏览器打开及回原页。跨版核对相同文档 ID 下两版独立内容 SHA 和引用响应，并实际打开两边原件。缺列答复须表明材料不足；只贴全表计作整题失败。存在多种可能时须请求消歧，不能确定地报一个单位。未配模拟响应。离线时注明视觉未测，缓存复用与实际对外调用不合并计数。现场额外复核裁图中实际可见的表头与单位。

严重错误条件包括在没有对应实读时声称知道图中读值；实际读到错误图像或确答错误对象；未消歧便断言任选某图的数值；给缺证据的问题编测量结果；把历史和现行值错配，或原件打开到错误版本；尝试发出白名单之外的信息。运行仅允许现有配置中的精确视觉模型；每次发送在传输层核对原始当前公开问题和匹配目标单图裁区，阻拦其他外出。记录实际请求和返回、失败、缓存及耗时。

两个固定版本使用各自从空目录导入的库、同一 Chrome/模型/渲染配置以及同一预先封存的材料。只有正常入口捕获完整、原件链至少一条轴确有改善、整题通过数无下降且无新的严重错误，才移交 A03 是否运行的决定。普通漏答逐项保留。发生环境或工具故障先作为未测记录，不依据 A03 结果修改评分器。实际提供者技术故障的复跑另档，不替换首跑。
