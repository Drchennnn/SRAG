# G08 · 讲义、表格与保存输出

普通问题明确要求定义或公式、表格及保存的实测输出时，工作区为三类各保留一项依据，旧的双项请求继续走 F。首次检索固定授权文档、版本、代次及原件哈希。角色判定取实际读取的原生内容，候选、页内重复文字及实验代码本身不计证据。句子中明确页或 Cell 但无法对应各文件时先澄清，避免替换指定位置。

分别核实原理出处及适用条件、与主题一致的原生表格行、同课程和实验标识的保存输出。只有原文明确提供可比较的上限，且指标、单位和条件同一，才给数值关系；比较结论同时引用上限和真实输出。缺角色时可从已读定义同段的唯一字面标识补查一次，补查只读原范围中同课程的文件。没有可核对锚就保留缺项。

## 公开验收

真实 Chromium 从空库导入新编脉冲门讲义与 Notebook 输出。普通三类问题明确缺少表格。加入带同指标、单位和留出条件的 PPTX 原生表格后再问，界面显示定义、保存输出和三个可回读的原件。比较只引用表格上限与实验输出，在这个量纲内得到 `0.29 ≤ 0.30`。打开实际引用得到原生 `page:1:shape:2` 与 `0.30`。两轮零外部调用。[浏览器证据](./G08-实测.json)

首审使用公开样例查出四类问题。基线专用或否定上限、额外条件、题目对象与表格列冲突、否定的实验切分，都可能错误通过。明确文件页码也可能被忽略。复审验证改为只接受字面明确的上限、单位、相同切分和已核对条件；串主题或切分的表不会承担结论。中英文实际读取、拒绝使用表格、指定页不存在、只命中父节点、范围及一次补查均有断言。
