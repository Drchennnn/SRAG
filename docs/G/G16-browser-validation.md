正式复审的六个 DeepSeek `deepseek-flash` 请求均 HTTP 200，含固定证据一轮及网页五轮。没有提供者失败、守卫拦截或生成复用。合计 8,642 tokens。固定证据生成耗时 2,428.519 ms，五轮本地 ASGI 耗时按顺序为 2,878.089、1,711.135、3,348.030、829.920 和 1,711.858 ms。九次原文引用打开均为 HTTP 200。图像预览的视觉读取状态为未尝试。 [实际请求、回答与打开结果](./G16-browser-live.json)

首次候选 `47a4e25e439955efc94685dc130230b701cbde88` 的执行者回放保存了六次 HTTP 200 和九次可打开引用。独立复跑同一候选时，首问声称有四轮，正文与原件都只有三轮，判作事实错误。修订候选后重放。校验器增加了未附排除条件的显式选项总数检查，日期和来源页仍逐项校验。 [首次执行记录](./G16-browser-first-live.json) · [独立首审错误](./G16-browser-first-independent.json)

校验器最初把 `partial` 一律挡下，复审候选的首个固定原文调用因此在进入浏览器前结束。记录显示全部必须的事实与引用都在，缺项是资格信手续和处理时长，以及能否推迟实习。校验器改为允许首问与固定原文在附有这些明确缺项时返回 `partial`，仍断言全部必需日期、限制和引用。早期单次 HTTP 200 与上表正式六次分开统计。 [复审首次固定证据记录](./G16-browser-final-gold-first.json)

## 复现

在已交付的 G16 提交检出中运行。原本机审核也可用上面的候选 SHA 固定 `G16_SUBJECT`。省略 `G16_ENV_FILE` 可用另一端口重放无 Key 的降级路径。浏览器每次从新目录和隔离会话开始。

```sh
G16_SUBJECT="$(git rev-parse HEAD)" \
  G16_ENV_FILE="$PWD/.env" G16_PORT=19146 bash docs/G/G16-browser.sh
G16_SUBJECT="$(git rev-parse HEAD)" \
  G16_PORT=19149 bash docs/G/G16-browser.sh
```
