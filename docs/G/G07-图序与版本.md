# G07 · 初始焦点、图序与双版本

“刚才”及点卡继续按完成消息的展示顺序，引用的是同一个保存的 `display_id`。普通首问“第二张图”在没有可用历史时，按当前原件中图片的位置定位。以当轮请求固定范围，多文件或多个可选对象时把澄清选项保存在轮次中，刷新后可继续选择。明确指向过去的请求找不到对应历史时提示补定位。当前图像复用 G06 的确认、裁区、字节及模型读取路径。

比较两个版本时，旧侧从本会话已完成消息中的原件引用授权。当前一侧回到最新快照，以所在文件、稳定的 Cell 标识及输出类型和位置等信息匹配。无法对应时给出缺项。选中两侧时，轮次提交在同一事务中验证历史可读及当前代次。文字和表格重读实际对象，分别标明版本并提供可开的引用。旧图使用原件授权校验与展示，只有与当前属性及旧图字节一致的原有可信读图才能支持该属性。旧图不重新发给模型。新图按当前属性单独读取，缺任何一侧均标明。

普通目录、点卡、F 双项及 G08 三类问答入口继续使用原有权限及证据合同。

## 公开复验

独立公用 Chromium 使用普通提问。在空图历史时，“刚才第二张图”返回澄清。选中当前 Cell 2 后，裸“第二张图”定位 v1 的 `cell:1:output:1`。另一个会话有两项歧义，刷新后选第二项得到同一 PNG。通过版本比较界面，打开旧 v1 的保存输出 `2.5 kHz` 和当前 v2 的同逻辑输出 `4.5 kHz`，各自的原件请求均为 HTTP 200。试验关闭视觉，零外部调用。[公开浏览器证据](./G07-实测.json)
