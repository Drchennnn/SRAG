# G10 M2 诊断协议

G09 基线固定为 `e921fa87f48a4e67c58010181a187c6e0e12b833`。运行使用干净检出、空资料目录和独立浏览器会话。G10 的四级诊断使用可分享开发资料。另由独立审核者准备内容、排版和对象顺序都不同的可分享资料及验收预期，等候选 SHA 固定后才与开发资料结果对照。两套都覆盖同页双图、表头与单位、跨轮换版、歧义和缺证据。A03 原题、原门槛及历史封存从 G09 沿用。

## 同题四级诊断

| 条件 | 提供的信息 | 检查点 |
| --- | --- | --- |
| 1. 普通网页原话 | 从网页输入，使用正常课程、会话和文件范围。通过正常界面打开引用 | 浏览器回答和最终可打开的引用。记录首轮候选及原因、选中对象、实际读取、展示、选中版本与回答。产品分只计这一行 |
| 2. 只给正确页 | 保持原问题，在独立诊断会话限定文件及页或 Cell，没有对象或裁区 | 正确父页内是否已存在目标，定位或阅读在哪一步偏离 |
| 3. 给正确对象与裁区 | 保持原问题和读取策略，在诊断会话给出版本化目标与边界。基线缺键时用隔离目录的 PDFium 独立探针核对物理对象和裁区，记录基线缺键 | 物理区域是否正确，应用能否显示、读取、引用同一对象；基线无对象时记不能通过产品入口指定 |
| 4. 给齐核验证据 | 记录读到的原文、坐标、单位和应支持的结论，连接同一答复路线的可注入环节时保存结果。无注入口时记录人工证据上限或模拟的范围和结论 | 齐备证据能否支持回答，产品答复遗漏是否始于证据组装。人工上限只支持区分证据缺失和推断可能性 |

执行以同一次资料导入、相同问题文本及对应版本为准。跨版问题固定先前已完成消息，避免跨会话带入焦点。各条件保存输入、输出、`document_id/version/source_id`、原件位置和最早偏离。歧义或资料缺失保留问清或说明缺项的预期。测试渲染、原生读取、模拟视觉、真实读图、缓存、失败与耗时各自记录。

## G11 允许改动的两处

- PDF 导入可登记底层解析器给出可靠边界的独立图片。来源属于同一文件版本和父页，记录 PDF 原坐标、可见区域坐标和旋转。涉及扫描、重叠或未知变换的对象时回退到页或澄清。有旧资料用同一原件重导，补登同版本下缺失的独立图像来源，验证既有页引用和历史原件仍可打开。保留原有版本键、权限和历史入口。
- 明确核对原表或具体列的首问，使用同一版本对象的原生读值、保留表头单位的裁区和可打开引用。缺可靠裁区时保留可核验的原生读值与原件入口，反馈裁区不可用。记录原生值实际来源。只渲染时视觉状态为未尝试。实际读图由现有授权路径处理。

## G12 与 G13 门槛

G12 在开发资料同一证据上用正式、口语和否定问法，核对跨轮变动前后两个来源均能打开。只有 G10 最早故障证据指向额外环节时允许提出一处变更。给齐证据依然答错时先检查证据综合。若独立新资料无净收益或出现新严重错误，G13 停在公开对照，A03 本轮未测。严重错误包括把错误对象、单位或版本当成已核验证据，越权访问，伪报视觉实读，以及破坏既有卡片追问和历史引用。

独立新资料有改善且无新严重错误时，独立执行者按 A03/G01 固定配置另档一次，先封存响应、引用、轨迹、耗时和调用量，再由独立评分者以原门槛评分。同一分母分别列首跑、G09 和本轮，日常题与保留题分列。私有题目、答案和可逆推出答案的轨迹在本机保留。G13 完成即停止，H01、J01 仍待架构负责人放行。
