## 复现

在仓库根目录执行。`G19_SUBJECT` 填已冻结的提交，未推送的审查提交在原独立工作区保留。已发布的实现可以用 G19 发布 SHA 重放。运行需要 Chromium 的 `agent-browser`、仓库 Python 环境和 LibreOffice。`G19_ENV_FILE` 默认读取当前仓库 `.env` 中已有的 DeepSeek 和 DashScope 配置。守卫只允许本目录生成的原件和固定的公开问题，实际发送的图像必须和这些原件的保存输出或裁图字节吻合。

```sh
G19_OUT=$(mktemp -d /tmp/srag-g19-browser.XXXXXX)
export G19_OUT
G19_SUBJECT=替换为固定提交SHA \
G19_SOFFICE=/Applications/LibreOffice.app/Contents/MacOS/soffice \
bash docs/G/G19-public-review/browser.sh
python3 docs/G/G19-public-review/collect.py "$G19_OUT" "$G19_OUT/replay.json"
```

`replay.json` 含候选、实读、版本化来源、模型载荷中的公开依据、原页打开情况和可见图序。`provider.jsonl` 另记实际发送及响应耗时，`http.jsonl` 另记应用端到端耗时。发布的最终逐轮证据 SHA-256 为 `fad06cb00de8286402bda4260c2e538e7826b36de2e8a9977d49457442566294`。
