# G19 独立公开网页复核

使用新编的棚架接头培训。先固定候选提交、课件文件摘要、问法、判据和正常网页配置，再从空目录运行。保留每次录制，记录 provider 实际请求与缓存。每轮只使用网页输入和正常资料库操作。按候选、实读、答案、引用四层判定，回答事实正确但引用错误时仍记该层失败。此处使用公开材料，也用于独立对照真实视觉。私有题的字段和权重沿用原口径，由其他审核者执行。

| 步骤 | 网页动作 | 人工裁决 |
| --- | --- | --- |
| 1 | 导入 PDF v1，选择整份资料，输入 `first`。 | 候选或完整顺序阅读覆盖第 3、6、8 页。回答用中文区分干燥无损初检（平衡后 6 分钟，不通电，非放行）、局部潮湿且无盐暴露的复核（至少 27 分钟、55–65% RH、三次）、正式放行（先通过复核，再签凭单和主管确认封签码）。逐个点开主张引用，确认实际 v1 页。欢迎页和演示的 12 分钟不能支撑正式条件。 |
| 2 | 输入 `summary`。 | 在两句内保留三种路径及决定条件。实际上一轮话题和所用的 v1 依据可回看，无空白或重复的英文摘录。 |
| 3 | 输入 `pdf_visual`。 | 独立位置问题指定右图。候选、选中对象、DashScope 图像摘要、bbox、`actual_source` 及点击后原件吻合。旧版图内右侧横轴标签为 `Rotation [deg]`，左图是温度。有模型调用才标真实视觉。 |
| 4 | 导入 Notebook v1，从资料库选中它，输入 `show_saved`。 | 页面实际展示两张图片。存 DOM 显示顺序、每个真实图片 URL/摘要和 `visible_display_ids`。原输出顺序还包含一条非图像 stdout。此次仅展示时图像未读。 |
| 5 | 普通输入 `second`，保留请求无 `anchor`、无证据 ID。 | 按上一步 DOM 顺序映射图 2。图像输入 SHA 必须等于上一次实际显示的第二张图，真实结果应为 `mm`。点这轮视觉结论引用确认打开相同对象与字节。 |
| 6 | 更新 Notebook 同一文件到 v2，重复 4–5。 | 同一 ordinal 瞄准新消息和新 v2；两张图顺序换位，图 2 的真实单位变为 `points`。旧的视觉引用仍打开 v1 `mm`，本轮不能复用 v1 图的视觉缓存。 |
| 7 | 更新 PDF 同一文件到 v2，选择整份并问 `pdf_v2`。再问 `version`。 | 当前答案必须是至少 34 分钟和 48–58% RH；短比较要明确旧版至少 27 分钟和 55–65% RH 的两个变化。保存可点开的 v1、v2 页号和渲染图；刷新后重新点击。 |
| 8 | 导入 PPTX，从资料库取消单一文件限定。普通输入 `cross_file`。 | 覆盖正确版本条件、PPTX 原表含 `Residual drift [mV]` 的 Sparrow 行 `3.6`，Notebook 保存 stdout 确认三次全部完成。证据缺项时亮明。三件来源可打开并与只读范围一致，记录补查是否执行及原因和新来源。 |
| 9 | 保持课程范围，普通输入 `missing`。 | 没有 72 小时盐雾 `Residual drift`，明确湿台 `3.6 mV` 不可代替。与原表的同名 Sparrow、另一型号的比较数 `11.8` 保持区分；若提及这些数字须明示其它条件和引用。 |
| 10 | 保持课程范围，普通输入 `composition_missing`。 | 同一缺证事实改成明确要求三类证据，以复测组合回答的调整。组合路线可以引用三类中与缺证判断有关的原文，不得把湿台值补成盐雾值，不得额外扩大范围或重复检索。此项在首轮发现组合缺陷后、修复候选运行前登记。 |

各独立环节出现错误时保留首轮文字、候选、真实读入对象、答复和可见引用路径。任意严重的串版、串对象、错用实验值、违背限定或捏造均阻断公开放行。若模型服务或测试工具阻塞，留运行时结果，恢复后从独立目录重放并保持首次记录。
