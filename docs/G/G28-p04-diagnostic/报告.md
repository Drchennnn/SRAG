## 最早可定位的偏离

**最早可证明的指代断点在生成请求组装前。** 首轮明确给出了目标话题，后续追问用代词指回它。收窄后，前一轮的一枚精确实验引用超出范围，`_scoped_previous` 遇到这枚引用便返回空值，连仍在范围内的话题也没有送入 `previous_context`。当轮问句原样传递，没有代词消解，也没有补入目标名称。正确原页仍通过阅读路径完整进入生成。范围提示使用独立的历史引用身份判断，因此能正确追加。该断点使回答缺少明确的指代锚点，首败证据无法进一步证明它是模型改答相邻概念的充分原因。

| 层 | 首败直接证据 | 固定实现核对与未知 |
| --- | --- | --- |

## 公开密集材料与上下文对照

用全合成的 24 页讲义和一份确定性实验 Notebook。目标定义与相邻概念分列，讲义含相近术语、实验指标定义和有先决条件的复杂度描述。每组首问都真实显示并打开实验引用。三组各有独立新会话，其中同范围组与隐式收窄组使用完全相同的追问。合成材料预生成后的清单哈希为 `dfd6def5bcdd3ee0c524494c965d6e1dadd78aa99f1b89dbac0099f0b7a69850`。

| 对照 | 生成输入实测 | 原始回答与最终块 |
| --- | --- | --- |
| I02 收窄，代词指代 | 无 `previous_context`。24 份当前讲义片段含目标原页，无旧实验输出。 | 两次均保留目标定义与条件，拒绝给旧实验值，追加范围外提示。均点击打开目标 v1 原页。 |
| E02 收窄，显式命名 | 同样无 `previous_context`。24 份讲义片段含目标原页，无旧实验输出。 | 两次均保留定义，指出缺少当前实验测量，范围提示正确，原页可点开。 |
| C02 保持课程范围，代词指代 | 实际传入上轮问答，且上轮问题含目标名称。12 份片段含定义原页和精确实验输出。 | 两次均保留定义及已在范围内的实测。打开两个正确对象，没有范围外提示。 |

首跑 6 轮、8 次真实模型请求，全部 HTTP 200。首跑记录到模型客户端入口消息、客户端返回正文、解析、筛查和网页最终块。出站抓取最初按 8,192 筛选，实发响应上限为 4,096，因此首批没有 HTTP 请求体记录。随后单独用新空库补跑同一公开清单，按生成系统提示识别请求，在 HTTP transport 捕获 6 个实际 JSON 体，并在客户端去空白之前拿到 6 个 provider content。补观测同为 8 次真实模型请求，全部 HTTP 200。两批的严格解析未删声明，技术筛查均删 0 条，筛查后正文逐条等于网页最终正文。39 枚引用全部首击成功。补观测记录未替代原首跑，也未用于填补封存首败的缺失层。 [公开阶段证据](./public-aggregate.json)

公开材料再现了**收窄时整个指代上下文清空**，没有再现**目标定义被相邻结论替换**。同范围对照同时改变了上下文与可用证据范围，可证明两条路径不同，无法隔离二者各自对模型选择的因果贡献。首败中的正确片段在生成输入，原始回复缺档，最有力的解释是请求失去显式指代锚点后，生成阶段选择了相邻事实。材料密度或附带结论对选择的影响仍未单独定量。现有证据不支持把责任归给检索漏取、技术筛查或提示拼装。原裁决保持返工，开发接手时以“指代锚点丢失”和“已经读取但没有回答目标定义”作为两个分别验证的问题。
