## 换版、缓存、回退与竞态

| 验证项 | 结果 |

| 换版竞态 | mock handler 内换版后响应被脱敏为 `stale_reference`，`display=None, reads=[]`，无旧图泄露。 |
| 迟到写回 | PPTX 删除后旧 source/hash/epoch 写回被拒绝；当前搜索无复活内容。 |
