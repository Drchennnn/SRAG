## 1. 实现范围

- `app/rag/source_vision.py`：DashScope 原生多模态协议、通用转写/定向追问、视觉缓存、
  跨服务实例单航班、授权复核与通用结果写回；
- `app/rag/source_evidence.py`：在 D02 请求/响应上向后追加 `read_intent`、`question`、
  `ReadRecord` 和 `external_call_count`，并提供同一服务端课程范围下的当前版复核；
- `app/api/source_evidence.py`：保持原 `/api/rag/local/evidence/current`，默认仍为
  `display_only`，显式读图才进入视觉服务；
- `tests/test_source_vision.py`：只使用公开 PDF fixture、隔离 SQLite/缓存目录与
  `httpx.MockTransport`，不读取 A03 私有题集，不调用真实模型。

生产调用需要同时满足 `source_vision_enabled=true` 和既有 DashScope 凭据非空；默认关闭。
外发前还会验证 endpoint 为带有效 host 的绝对 HTTP(S) URL，拒绝内嵌认证、query、fragment，
并拒绝含空白、控制字符或非 ASCII 字符的 Bearer token。无效配置不影响 D02 展示，但读图降级为
`not_attempted/provider_not_configured`，计数为 0。
协议依据为阿里云 Model Studio 官方说明：
<https://www.alibabacloud.com/help/en/model-studio/qwen-api-via-dashscope>。实现直接调用原生
`/services/aigc/multimodal-generation/generation`，每轮只发送一幅 D02 已展示图片的 data URI
和一段文本提示，无自动重试，超时限制在 0.1–60 秒。

## 2. 展示对象与实际读取对象

读图请求先完整执行 D02。模型收到的字节必须同时满足：

1. `base64` 严格解码成功；
2. 长度等于 `DisplayRecord.byte_length`；
3. SHA-256 等于 `DisplayRecord.byte_sha256`；
4. MIME 为 PNG/JPEG/WebP，且未超过配置上限；
5. `actual_source + content_sha256 + publication_epoch` 在外发前仍是允许课程中的当前版。

`ReadRecord.requested_source` 保留调用方请求，`actual_source`、`actual_input_sha256`、MIME 和
裁区记录模型实际读取的 D02 输出。两个不同子对象即使都回退同一父页，也不会复用带有另一
请求对象身份的记录；缓存键包含 requested/actual SourceKey。父页回退的通用转写只允许写回
`actual_source`，定向追问永不进入 FTS。

## 3. 状态与真实调用口径

| 情形 | `read_status` | `capability_reason` | `execution` | `external_call_count` |
| --- | --- | --- | --- | ---: |
| 未请求 | `not_attempted` | `not_requested` | 无记录 | 0 |
| 功能关闭 | `not_attempted` | `provider_disabled` | 无记录 | 0 |
| 功能开启但无凭据 | `not_attempted` | `provider_not_configured` | 无记录 | 0 |
| 输入不支持 | `not_attempted` | `input_unsupported` | 无记录 | 0 |
| 协议模拟成功/失败 | `not_attempted` | `mock_only` | `mock_protocol` | 0 |
| 真实成功 | `succeeded/partial` | `null` | `real_provider` | 1 |
| 真实失败 | `failed` | `null` | `real_provider` | 1 |
| 真实成功缓存复用 | `succeeded/partial` | `null` | `cache_reuse` | 0 |
| 外呼后来源失效 | `not_attempted` | `input_unsupported` | 记录清空 | 1 |

模拟模式只能接收 `httpx.MockTransport`，且拒绝任何真实 API key；真实模式拒绝自定义
transport。两种模式各自进入不同缓存命名空间，模拟结果不能冒充真实成功，也不能写 FTS。
D03 本次真实外部供应商调用为 **0**；专项测试实际执行 30 次本地 MockTransport 协议调用，
并对一个临时未监听的 loopback 端口执行 1 次真实 HTTP 连接失败回归，用于证明有效 endpoint
的连接/请求失败仍保留调用计数。另有两次
直接注入 provider 回调的竞态单元测试，只验证真实路径的计数与脱敏语义，并没有发出网络请求。
D04 才在公开 fixture 上执行有界真实调用并记录服务端 request id/usage。

## 4. 缓存、并发与损坏隔离

视觉缓存键覆盖：

```text
schema + requested_source + actual_source + content_sha256 + publication_epoch
+ rendition_kind + actual_input_sha256 + MIME + rect
+ purpose + execution_kind + provider + model + prompt_version + question_sha256
```

同一 `(cache_dir, key)` 使用进程共享单航班；API 即使每请求创建新的服务实例，也只让一个
调用进入 provider，不同 key 可并行。命中缓存后不只信任文件名：持久记录的 requested/actual
SourceKey、图片哈希、MIME、rect、purpose、真实/模拟来源、provider、model、prompt 和问题
哈希必须逐项匹配，否则删除损坏缓存并重读。失败、截断、HTTP 错误和损坏 JSON 不写成功
缓存；临时文件经 `fsync` 后原子替换。

## 5. 授权竞态与回写

当前版授权至少在 D02 展示后、缓存读取前、provider 外发前、provider 返回后、通用写回前、
缓存落盘前和最终交付前复核。等待期间发生换版、删除或撤权时：

- 返回 `stale_reference`；
- 清空旧 `display` 与 `reads`，不返回旧图片、文本、request id 或 usage；
- 已发生的真实调用仍由 `external_call_count=1` 留痕；
- 不写视觉缓存；
- B 的 `write_enhancement` 再用实际 SourceKey、哈希、epoch 和服务端课程范围做事务内复核。

专项回归分别覆盖“provider 成功期间换版”和“provider 失败期间换版”，两路都只返回脱敏 stale
结果并保留调用计数。通用转写的真实来源记录可写入实际图片来源；删除后的迟到写回被 B 拒绝。

## 6. Provider 响应边界

只接受官方 choices/message/content 结构与 JSON 对象输出。定向问题要求非空 `answer`；通用
转写要求 `text`，并可带 formulas/symbols/descriptions/uncertain 字符串数组。以下情况安全归为
失败且不缓存：

- HTTP 超时或非 2xx；
- 顶层 JSON 是数组/null，choices 缺失；
- content 不是支持的字符串/文本块；
- finish reason 为截断或未知值；
- usage 不是对象或 token 值不是整数；
- 模型 JSON 字段类型错误或正文为空。

响应错误只对外暴露受控类型或 HTTP 状态码，不拼接供应商响应全文、任意错误码或未经筛选的
finish reason。
