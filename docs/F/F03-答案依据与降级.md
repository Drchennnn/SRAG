# F03 · 按本轮原文回答

实现以 F02 远端签认版本 `7b622dde70549c2a4eb11d0bbf2774ca764f4818` 为基线。F03 复用 F02 的版本化线索、原文、支持和缺项，给出离线、可逐条核对的回答。入口是 `EvidenceAnswerer` 和 `python -m tools.evidence_answer`，均使用当前本地 B/C/SQLite 数据。[F02 实现](./F02-一次追加检索.md) · [F01 签认设计](./F01-一次补证据设计.md)

## 回答与引用

`EvidenceAnswerer(retriever).answer(request, allowed_course_ids=..., strategy=...)`
返回 `AnswerRun`，结构化 `answer` 与 F02 的 `retrieval` 分开。内用
`compose(report, allowed_course_ids=...)` 只接收当前应用进程的 F02 结果，公共 CLI
从问句和授权范围开始。两种策略使用相同的最终证据预算 `K`。

| 内容 | 输出约定 |
| --- | --- |
| 定义 | 逐字呈现已读定义，自带本轮 `evidence_id` 和字面跨度 |
| 实验 | 按每个文件的实际记录列明实验标识、切分、指标、单位、基线、试验值和样本数 |
| 同条件下数值冲突 | 标记 `conflicting`，保留/引用每条合法的比较；指标与切分别名按 F02 归一，单位原样区分大小写 |
| 条件不同 | 切分、指标、单位或样本数不同的记录分别显示 |
| 缺项 | 仍返回可核对的部分，并标记缺失的定义或实验 |

每条陈述及引文经以下校验后进入回答。

1. 校验最终证据预算、去重源键、初查全量范围及发布元组。源键必须属于同一版本的当前获准范围。
2. 本轮 `reads` 与 `final_evidence` 中的 `evidence_id` 唯一且一致，引用解析到同一实际
   `SourceKey` 的成功或适用的部分原生读取。使用 B 重读实际被引用的源，校对哈希、代次、原文位置和全文或精确读段。只有候选、模拟、旧轮或预算替出的来源不会进入答案。
3. 半开字符跨度 `[start,end)` 必须能从相应读段切出完整引文。再用签认 F02 的定义主题和同课实验条件检查，重建原文支持。只篡改结构化值而保持引文也会失配。
4. 交付前再次复核全量首跳快照及授权。改版、同字节新代次、撤权或取消时抑制陈述及旧轨迹，返回失效原因。单一原件无法验证时去掉相应主张，保留其他已确认部分。追加检索失败但初查仍有效时可继续给出已确认定义。文本格式化失败时降级为已核对的结构化 JSON。

`answer.verified_source_count` 统计通过答复复验的来源。F03 使用无 MATCH 版本检查和 B 原文读取复验，候选批次及 `supplement_count` 仍只记录 F02 检索。回答的数字、条件和引文都来自本轮原文，模板没有计算因果、统计显著性或通用结论。

## 真实调用结果

使用隔离 SQLite 导入同一套 [SignalTrialA7 公开样例](./样例/SignalTrialA7.json)，以两个独立的
`python -m tools.evidence_answer` 进程实跑。测试进程和此处实跑均阻断 socket 连接。

| 模式 | 补查 | 最终 K | 答案 |
| --- | ---: | ---: | --- |
| `single` | 0 | 2 | `partial`，仅引用 `Median-lecture.ipynb / cell:0` 的中值滤波定义，实验缺项 |
| `supplement` | 1 | 2 | `complete`，保留同一定义，并引用 `A7-observations.ipynb / cell:0` 的四个留出集样本记录。MAE（amplitude）基线 0.24，试验 0.18 |

逐跳追踪里的源键、证据 ID、候选取舍和停止原因均可通过 `--trace` 重放。CLI 默认文本
输出，并把原文当作纯文本。JSON 保留可精确校对的源跨度。除公共样例外，真实课程的原文轨迹只留在调用环境。

从仓库根目录执行以下子 shell，三份 Notebook 在临时目录生成。测试未使用保留题答案。

```sh
(
  replay_dir=$(mktemp -d /tmp/srag-f03.XXXXXX)
  export COURSE_ROOT="$replay_dir/courses"
  export SQLITE_PATH="$replay_dir/library.sqlite3"
  export DATA_DIR="$replay_dir/data"
  export SRAG_STRUCTURE_COURSES=signal-demo
  mkdir -p "$COURSE_ROOT"
  .venv/bin/python - <<'PY'
import json
from pathlib import Path

import nbformat

from app.config import get_settings
from app.rag.local_library import LocalLibrary

sample = json.loads(Path("docs/F/样例/SignalTrialA7.json").read_text(encoding="utf-8"))
library = LocalLibrary(get_settings())
paths = []
for document in sample["documents"]:
    path = library.course_root / document["file_name"]
    cell = nbformat.v4.new_markdown_cell(source=document["text"], id="evidence")
    nbformat.write(nbformat.v4.new_notebook(cells=[cell]), path)
    paths.append(path)
assert all(item.status == "published" for item in library.import_paths(sample["course_id"], paths))
PY
  question='中值滤波 median filter 的定义是什么？课件所对应的留出集实验如何验证？'

    --course signal-demo --top-k 2 --strategy single --trace

    --course signal-demo --top-k 2 --strategy supplement --trace
)
```

`--file` 或 `--document` 缩小范围，`--json` 只输出答案，`--trace` 附带逐跳数据。
