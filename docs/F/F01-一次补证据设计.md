## 接口与本轮事实边界

内部调用由可信应用层提供原问题、有效课程访问上下文、C 的文件/位置筛选、策略 `single` 或 `supplement`、最终证据上限 `K`、取消回调。公开调用不可用自带课程 ID 扩大服务器授权。F 将解析后的范围作为 `TurnScope`，按 `SourceRevision` 校验来源、原件哈希与代次，用 `TurnRead` 封装事实摘录、用 `TurnEvidence` 传给 E。逐跳轨迹、支持映射、缺项和停止原因由 F 输出。其中的本轮引用通过唯一的 `evidence_id` 关联。具体字段见[本轮证据接口](../E/本轮证据接口.md)。

| 要求 | 支持条件 | 仍缺的情况 |
| --- | --- | --- |
| `definition` | 当前授权来源成功读取的定义段，直接说明术语和方法 | 只有关键词、标题、相邻位置或旧轮引用 |
| `experiment` | 与已读定义锚点同课程的另一个获准文档的当前原文，明确关联定义指向的实验标识，且给出实际对照、同一指标/单位、样本条件和结果 | 仅实验计划、同名方法、不同实验标识、另一课程复用了实验标识、查询要求留出集却来自训练集、结果或条件缺失 |

首版用轻量规则识别问题中的定义与实验线索（例如“定义 / definition”及“实验 / 验证 / experiment”）。不明题型按初查结果返回可核对原文和实际缺项，无自动追加。实验限定词和关系以结构化记录判断，离线规则可核对的最低支持门槛是“一个具有字面且可溯到的定义、一个可核对的实验标签及对应结果”。规则以受控可读语段工作，对自由表述保留覆盖缺口。

读证据的最小单元是一个 A01 源键和其受限字面摘录，带课程、时刻校验的版本哈希与发布代次、位置、`evidence_id`、读状态和读方法。首版用 B 的 `LocalLibraryStore.read_source()` 取得当前授权的原生文字，要求 `status=available`、原件哈希、当前版和代次一致。读取 `SourceDraft.text` 的某段后才能标为 `native_text/succeeded` 或部分读到的 `partial`。缺原件、纯图无文字或读失败留状态，不能贡献追加词或实验结论。C FTS 命中、增强索引命中、D 图片已展示、模拟结果和旧会话引用属于候选或轨迹。D 如提供本轮真实读取记录，保留其实际源键、输入图哈希和状态；首版追加词和离线结论仍来自成功读取的原生文字。客户端传入的字符串或旧读记录不能替代重新读取。

## 冻结范围和一次追加

1. 用同一个 C `StructureSearcher.search()` 进行初查。单跳与追加采用同样的题面、C 参数和 `top_k=K`；成对验收固定初查关闭邻接，两边共同使用同一个初查结果或逐项确认候选、排序及快照完全一致。首跳的 C `snapshot` 保留 **整个有效文件集合**，包括无首跳命中的文件。每项固定 `(course_id, document_id, version, content_sha256, publication_epoch)`。名称歧义先由调用方澄清。只要 C 返回 `scope_not_found`，即使附有部分已解析文档也按原请求范围失败处理，保留 C 状态和可公开的缺项，停止读取及补查。
2. 在本轮预算内读取初查候选，用实际文字判定支持和缺项。已有两项则结束。缺定义、没有可证明的已读锚点、单文件范围或仅选定某个页/Cell 时，保留已确认部分。补查不得让显式位置限制变成跨文件范围。
3. 只有 `experiment` 缺失且定义已支持时才提取追加词。首版从定义段中的显式实验标识抽取最多一个安全的字面标识符，约束为 ASCII 字母数字，首字符为字母、总长 5–40。保存锚点课程、源键、读证据 ID、`excerpt_sha256`、于同一个确切摘录内的零基半开字符跨度、字面值和首轮是否已用。词已在首轮查询或词法变体中使用、仅能推断/翻译、仅在文档名或检索结果标签出现时，结束并记录原因。多个已读定义来自不同课程且题面没有明确目标课程时保留歧义，等待用户选择。测试必须能够从记录中的字面跨度机械切出相同字符串。
4. 原始快照按锚点的已核对 `course_id` 求交集，得到补查唯一可访问的冻结文件子集。即使其他课程在首轮同时授权、被明确选中且有相同实验标识，也不进入补查；首查候选走相同的同课程归因规则。子集中只有讲义或缺独立文件时记录 `scope_limited`。补查通过 C 的 `StructureSnapshotStore.read(SnapshotRequest)` 复用快照及 FTS，用锚点课程及该子集非空文档 ID 列表做一次参数化的 FTS5 引号字面匹配，候选上限 `K`。补查发出前锁定本轮一次机会。词计划按字面展示，文件筛选沿用已解析的 ID 集合。补查不用 C 公共查询的术语表、代码子词、邻接或更宽课程。
5. 补查返回的版本快照与首跳锚点课程的子集逐项比较。使用同一快照存储、全量首跳冻结的课程与文档集合做无 MATCH 的复核（`fts_match=None, fts_limit=0`），与全量首跳按 `(course_id, document_id, version, content_sha256, publication_epoch)` 比对。复核不产候选，按 `snapshot_recheck` 类型另计，补查计数只包含一次新增字面 MATCH。任一首跳文件失效即终止，包括首跳没命中或不在锚点课程子集内的文件。读取每个候选、调用补查前以及准备交付答案前都复核当前授权与原件版本。失效轮只交付可见的失败状态。收到取消时停止后续读取和查询，丢弃在途结果。调用方可在最新快照主动发起新轮。
6. 用完整 A01 源键去重，记录返回的每条候选是新证据、复现首轮源、错配或无法读取。再次检查原文中是否确有相同实验标识、同一对照条件。一次补查返回的重复对象不递归拉取下一页；本批中其他已返回候选仍可在预算内核对。跨文档相同摘录也只计一个事实支持，轨迹留各自源键。内容相同仍保留独立的资料身份。

## 同预算取舍和逐项生成

- 最终预算 `K` 按唯一 A01 源键计数，两策略都限制 `len(final_evidence) <= K`，同一证据可服务多个要求。初查最多读取 `K` 个候选，补查另有最多 `K` 个候选的核查成本；两者分别报告实际读取、耗时、补查次数和最终证据数。最终预算与工作量差异分别列明。
- 初查的唯一有效定义证据优先保留。可证明补齐必需项的候选若满额，可替换最低优先级的辅助原文，初查次序用于同优先级决胜。裁剪后的作用按最终集合重新判定。全是必要证据且没有可安全释放的槽位时停止在 `budget_exhausted`。轨迹逐项保留被替换的源键、位置、原作用及理由。错配、重复和读失败不挤掉现有证据。
- F03 输出按要求的短陈述、`supported/missing/conflicting` 状态，以及当前 `evidence_id` 和确切引文。冲突保留各自来源、实验条件、单位和数字；缺一项时仍列出已确认部分和缺什么。模板可直接用本轮读到的定义、比较值及条件，计算可复算差值时明确算式。不加原文没有给出的因果解释、普适结论或模型推测。答案消费方引用仅限最终集合，排除的候选仅用于诊断。轻量路径通过 SQLite、规则和原文独立运行，F01–F04 本阶段不验收 Jev 或外部模型收益。
- 轨迹中记录策略、原问题、`K`、初查有效范围及版本、每跳候选源键/排名/源读状态/耗时、已支持/缺项、补查词的锚点、重复或错配原因、最终证据和替换。顶层有 `status` 与 `stop_reason`，追加执行后保留 `supplemented`、`duplicate_only`、`mismatched`、`no_additional_evidence` 或 `still_missing`。未调用补查时可能为 `single_hop`、`already_supported`、`no_new_terms`、`scope_limited`、`budget_exhausted`。取消、授权变化和版本不一致分别留下 `cancelled`、`not_accessible`、`stale_snapshot`。服务异常保留可核对的已确认部分与 `search_failed`，版本或权限失效时按上述规则抑制原文。

## 公开验收题与逐跳预期

以新建的公开合成课件和 Notebook 验收，固定原生片段和源定位，所有样例生成在隔离目录。题目是“中值滤波 median filter 的定义是什么？课件所对应的留出集实验如何验证？”以下是验收向量，导入会生成真实 `document_id`；表中的 `lecture`、`notes`、`lab` 是同一个公开课程 `signal-demo` 内的角色标签。讲义与辅助说明可用 Markdown Notebook Cell 承载，实验结果由已保存的 Notebook Markdown Cell 承载。

| 文档与预计源位置 | 固定原文或作用 |
| --- | --- |
| 讲义 `Median-lecture.ipynb` 的 `cell:0` | `Definition: A median filter replaces each interior sample by the median of an odd window.` 后接 `Experiment-ID: SignalTrialA7.` |
| 辅助说明 `Median-drills.ipynb` 的 `cell:0` | `Median filter worksheet: practice selecting odd windows without reporting an outcome.` |
| 实验 `A7-observations.ipynb` 的 `cell:0` | `Experiment-ID: SignalTrialA7. Split: held-out. Metric: MAE. Unit: amplitude. Baseline: 0.24. Trial: 0.18. Samples: 4.` 另存两组逐窗绝对误差，`(0.20, 0.24, 0.28, 0.24)` 与 `(0.16, 0.20, 0.18, 0.18)`，可人工复算。 |

首轮用户题面未含实验代号或结果，两个策略在 `K=2` 时取同样的 `lecture`、`notes`。本轮已读定义支持“用奇数窗口的中位数替换内点”，辅助说明未支持实测结果。精确补词锚点是讲义原文的第二句；将这句作为用于补词的独立摘录时，`"Experiment-ID: SignalTrialA7."` 的第 `[15,28)` 个字符严格为 `SignalTrialA7`。完整证据与该跨度记同一 `SourceKey`，由实现记录原文摘录中的真实偏移。初查锁定的课程及三份文档版本保留不变。

单跳返回定义及实验缺项。追加一次找到新实验原文，实验标记、留出集和两组 MAE 经读证据确认。保留讲义，辅助说明退出最后两个证据槽位；轨迹列明其源键和退出原因。可支持的结论是“该公开四窗留出集合成试验的 MAE 从 0.24 到 0.18（幅度单位）”，并逐项附两处当前原文引用。这个结果只描述该验收向量中的比较。

| 变体 | 两组共同的输入约束 | 预期 |
| --- | --- | --- |
| 重复 | 课程范围只留讲义及练习；搜索可返回原讲义的实验标识 | 追加批只返回已读对象，`duplicate_only`，保留定义和缺项 |
| 错配 | 另有同一标识的训练集报告，题目固定要求留出集 | 记录训练/留出条件不符，`mismatched`，保留原候选 |
| 仍缺 | 追加命中同一标识且切分正确，仅记录实验计划或一侧数值 | `still_missing`，不给比较数值 |
| 越界 | 非授权课程或显式文件集之外有精确匹配，原范围内只保留重复/缺项 | 真实补查范围仍是冻结课程/文档，候选和答案无越界来源 |
| 两课同时授权且选中 | 讲义来自 A；B 课具有相同 `SignalTrialA7` 及匹配的留出集记录。A 内保留一份其他文件但没有实验记录 | 全量首跳快照仍含 A 和 B；追加仅 A 冻结子集，实验缺项。另让 B 的同标识实验直接进入首跳，仍不得支持 A 定义对应实验 |
| 部分文件解析失败 | 请求指明一个真实文档 ID 和一个无法访问或缺失的 ID，C 返回 `scope_not_found` 并附部分实际文档 | 传播 `scope_not_found` 与经授权的缺项，0 次读取、0 次补查 |
| 单文件/指定 Cell | 题目要求两项但有效范围只含讲义或限定于一个对象 | `scope_limited`，0 次补查 |
| 有定义无新增词 / 预算已满 | 删掉讲义标识或在题面加入它；另测 `K=1` 保留唯一已支持项 | 前者 `no_new_terms`，后者 `budget_exhausted`，均为 0 次补查 |
| 取消与快照变化 | 在初查后与补查返回时各做取消；另测补查进行中改版、删后重导、撤授权 | 不再读无效候选，不使用新旧混合证据；后续查询次数受限，失效报告不泄漏 |
| 冲突 | 同一已登记实验的两个授权报告给不同 MAE，或同指标分训练/留出 | 足够预算时逐条件引用；不将不同条件合成为一条无条件结论 |

## 验收与送审

- F01 的隔离 SQLite 设计探针已把上述三段原文导入为三个临时 Notebook。C 首查按序返回讲义和练习，快照仍包含实验；B 当前读取能取得讲义真实字面锚点；使用 C 的快照存储查一个 FTS 字面词，按序返回实验、讲义。四窗 MAE 和 `[15,28)` 也经独立计算核对。审核者可按上述输入新建临时文件复算；F 的候选选择、截断与答案行为等待实现测试。设计任务仅增加本文件。
- F02 对应计划中的本地测试 `.venv/bin/python -m pytest -q tests/test_evidence_supplement.py`。使用真实 B 导入、C 搜索和隔离 SQLite 跑上述矩阵，注入计数适配器证明次数。每个变体同配置成对跑两策略，比较初查有序源键列表、快照、K、最终证据、引文跨度与错误分类。
- F03 对应测试 `.venv/bin/python -m pytest -q tests/test_evidence_answer.py`。把候选、已读、最终裁剪三层分开，断言每条事实引用的 ID 属于当前最终集合且引文能从相应源文本复核，验证定义可用、实验缺失、同条件冲突及格式化失败降级。
- F04 独立审核需从干净公开归档创建隔离课程及 SQLite，冻结配对快照与原始题面，保留真实 SQLite 检索及人为构造故障的区别。逐项报告支持、错配、重复、缺项、预算取舍、耗时和外部调用计数。独立调用可供 E 后续消费；E/F 浏览器联调和 G01 放行由架构负责人另行决定。
