## 同预算实测

每组先将文件导入独立空库，再用同题、同选择范围、同一数据库分别运行单跳和补查。代码
逐项核对两组的**全量快照、首跳候选、受检范围、首跳 MATCH 与最终证据上限**；
上限均为 `K=2`。首轮依次取得讲义与练习，支持定义，实验缺项。六组的单跳均
`partial/single_hop`，执行一个逻辑 MATCH。补查均只追加一个逻辑字面 MATCH，最终保留
两项证据。无 MATCH 的发布版本复核单独计数。

| 场景 | 补查结果 | 事实与取舍 | 单跳 / 补查总耗时（ms） |
| --- | --- | --- | ---: |
| 补齐且首轮已占满 K | `supplemented`。重复讲义和新实验进入补查候选 | 保留讲义与实验，练习被替出且未被引用。引用定义和实验 | 9.793 / 11.251 |
| 库中只有讲义与练习 | `duplicate_only`，补查只得到重复讲义 | 保留首轮定义，实验缺项 | 7.538 / 10.329 |
| 本课实验为训练集 | `mismatched`，`experiment_split_mismatch` | 题目要求留出集，拒绝训练集数字，保留首轮定义 | 7.396 / 10.365 |
| 缺少试验值 | `still_missing`，`experiment_fields_missing` | 实验有正确 ID、切分及基线，仍缺试验值，引用只到定义 | 7.671 / 10.675 |
| 同时授权并选择两门课 | `duplicate_only`，外课含同 ID 和可读比较 | 外课在首轮全量快照中。补查范围仍是锚点课的讲义与练习，仅引用定义 | 7.538 / 9.154 |
| 显式仅选讲义和练习文件 | `duplicate_only`，同课实验文件未在所选快照 | 补查未越过两文件范围，保留定义和实验缺项 | 7.448 / 9.365 |

第三、四行都真实读到实验档，保留其原文、读状态和拒绝原因，事实答案保持部分支持。表中耗时
是单次独立审核的程序内实测。正例第二跳耗时约 0.723 ms；真实 CLI 的
`single`、`supplement` 进程墙钟分别为 326.413、313.176 ms，含进程启动，未用作性能比较。

## 正例逐跳对照

问题为“中值滤波 median filter 的定义是什么？课件所对应的留出集实验如何验证？”
两策略首轮的资料与实际读取对象如下。标识来自本次隔离导入。

| 顺序 | 本次证据和来源三元组 | 已读和作用 |
| --- | --- | --- |
| 1 | `ev-1` → `(local_8bb7646403124a158c5c6346bc505add, 1, cell:0)`，`Median-lecture.ipynb` | 原生定义支持“以奇数窗的中值替换内部样本”。同一已读 Cell 邻接行标明实验 ID |
| 2 | `ev-2` → `(local_6d82b998a9b54da3b9ec780ecaef1ed4, 1, cell:0)`，`Median-drills.ipynb` | 原生练习文字可读，缺实测比较 |

F 从 `ev-1` 的相同已读原文截取零基半开字符跨度 `[105,118)`，逐字等于
`SignalTrialA7`。该原文 SHA-256 为
`2b41898e190bffee7de25607b91f1e9394b2486fc79df48f3e820fe075317ee1`。
第二跳只执行字面 `"SignalTrialA7"` MATCH，在原课程和已冻结文件集合里得到重复的讲义及
新实验 `ev-3`，位置为
`(local_00b71d07c38b4647a34f659a604190fb, 1, cell:0)`，
`A7-observations.ipynb`。补查以实验替出辅助练习，最终 `ev-1, ev-3`。

实验源记录留出集四个样本，指标是 MAE，单位 `amplitude`，基线 `0.24`、试验
`0.18`。公开原文两组四个绝对误差的均值复算一致。每条最终引文的
`evidence_id`、实际 `SourceKey`、读取状态及原文字面范围均与保留的本轮证据一致；
预算淘汰项无最终引用。CLI 的 JSON 事实与同库 F03 调用一致。
