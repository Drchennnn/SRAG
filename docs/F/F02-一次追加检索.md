# F02 · 一次字面补查

实现基于远端 F01 签认版 `058a6a7c15dec76cdf55d351142a3cf088417bbc`。本任务增加内部调用 `SupplementRetriever`，运行于当前 B/C 的 SQLite 资料库。读证据使用 E/F 共用的 `TurnEvidence`。F02 输出支持引文和缺项，F03 将其编排成面向用户的回答。[签认设计](./F01-一次补证据设计.md) · [共享接口](../E/本轮证据接口.md)

## 调用和轨迹

```python
from app.rag.evidence_supplement import SupplementRetriever
from app.rag.local_library import LocalLibrary
from app.rag.structure_search import StructureScope, StructureSearchRequest
from app.stores.structure_snapshot import StructureSnapshotStore

library = LocalLibrary(settings)
retriever = SupplementRetriever(library.store, StructureSnapshotStore(settings))
request = StructureSearchRequest(
    query="中值滤波 median filter 的定义是什么？课件所对应的留出集实验如何验证？",
    scope=StructureScope(course_ids=["signal-demo"]),
    top_k=2,
    include_adjacency=False,
    include_page_fallback=False,
)
result = retriever.retrieve(
    request,
    strategy="supplement",
    allowed_course_ids=frozenset({"signal-demo"}),
)
```

运行前在受信任的临时课程根目录导入[公开样例](./样例/SignalTrialA7.json)三段。每条生成一个 Notebook 的 Markdown Cell，导入后对象为 `cell:0`。测试中的 `publish()` 提供可重复的 B 导入。上例的 `settings` 指向测试专用的 SQLite 和目录。

`allowed_course_ids` 可由内部调用方传入受信任的权限查询函数，允许运行中撤权被复核。传冻结集合仅适用于本轮不会变化的既知权限。取消由内部回调给出。需要以合法角色创建的一组 `course_ids` 和 `document_ids` 作为入口范围。C 未能解析完整原范围时返回 C 状态和缺项。版本或权限变化会丢弃此前的快照、正文、支持和候选，仅保留失败原因及已发生的工作计数。

报告的 `hops` 记录检索批次、实际范围、字面词、候选顺序、来源、状态和查询耗时。`reads` 记录实际读取过的原件摘录及失败，`final_evidence` 是预算内最终证据。最终 `supports` 引用当前最终集合中的 `evidence_id`，用字符跨度指出实际读到哪一段。新增词字段保留完整读段哈希和零基半开跨度。F02 按资料中的显式定义段和实验字段判断。没有足够文字、条件缺失、实验来自别课或同课重复等只影响候选及缺项，不会凭索引匹配生成事实。

定义的实验标识须在同段，且紧邻定义行或与定义同一行。英文 “definition of …” 或 “define …” 及中文“……的定义”提取显式主题，定义原文的开头须与主题短语或它触发的 C 注册别名相符。合并题中后续实验或比较分句的词表变体只参与首查候选。主题片段内有括号、排除、比较或并列成分时，保守保留定义和依赖它的实验缺项，追加次数为零。实验行的切分、指标、单位、基线、试验值和样本数来自同一连续记录，Markdown 标题、空段和插入的其他数据说明均会分开记录。题面明确指明切分或受控指标别名时，与原文字段逐项核对。识别到切分/指标条件歧义、条件否定、实验计划、提案、假设数字、预期结果或未实测声明时保留实验缺项。

F02 的新增补查是一个带字面 MATCH 的 C 快照调用。C 内部为同一次候选批执行 SQLite 查询组成候选和来源。`supplement_count` 计候选批，`snapshot_recheck_count` 单计无 MATCH 的版本检查，`source_read_count` 单计 B 读取。跨文件补查只访问定义锚点课程的冻结文档子集，同时复核首轮完整版本、原件哈希和代次。
