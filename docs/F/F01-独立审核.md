## 独立探针

在临时课程目录及 SQLite 独立导入设计中的三个 Markdown Notebook，另加同时获准的
`other` 课程下 `Cross-course.ipynb`。错课 Cell 使用相同 `Experiment-ID:
SignalTrialA7`、留出条件及不同的 MAE 数字。设置忽略 `.env`，未联系外部模型。

1. 用设计题面执行 `StructureSearcher.search`，`top_k=2`、`include_adjacency=False`。
   实得首查讲义、练习，固定快照有四份文档，包含无首查命中的实验。
2. `LocalLibraryStore.read_source` 返回当前版，原件哈希和发布代次与首查一致。讲义原文
   `Experiment-ID: SignalTrialA7.` 的 `[15,28)` 精确为 `SignalTrialA7`。
3. 用 `StructureSnapshotStore.read` 对两个都获准的课程运行引号包裹的字面 MATCH，
   返回错课实验。按锚点的 `signal-demo` 及该课程三个冻结文档收窄，同样上限 2，仅返回
   讲义和正确实验。两组公开四窗绝对误差重算 MAE 为 `0.24` 和 `0.18`。
4. 显式提交一个存在及一个不存在的文档 ID，底层实得 `scope_not_found` 与一份已解析文档，
   无 FTS 种子。这证明 F 层需要按状态封闭部分结果。
