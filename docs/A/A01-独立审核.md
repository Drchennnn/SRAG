```sh
git rev-parse HEAD
shasum -a 256 RAG.md docs/A/A01-公共契约.md docs/A/A01-契约样例.json
```

使用 python-pptx 打开 PPTX，枚举第 1 张的 `shapes`，读取 `shape_id`、`left/top/width/height` 和表格单元格；用原页宽高归一化即可得到上述框。使用 Python `json` 直接读取两个 IPYNB，取 `cells[1].outputs[1:3].data["image/png"]`，base64 解码后计算 SHA-256 并用图片查看器查看标签。再按 `message.blocks` 过滤 `type == "source_image"`，顺序检查 `display_id` 和 `display_source`；按三元组集合验证所有父键、证据、显示及失败向量的参照完整性。
