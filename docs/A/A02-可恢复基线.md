### 终端和检索接口

当前工作区和恢复目录分别运行 `python -m tools.chat --help`，得到相同入口：

```text

                            [--contextual | --raw] [--log LOG]
```

恢复目录另外以同一隔离环境运行以下六项已有测试：

```sh
/Users/Link/code/SRAG/.venv/bin/python -m pytest -q -p no:cacheprovider \
  tests/test_chat.py::test_chat_flags_invalid_citation_number \
  tests/test_chat.py::test_cli_file_selection_is_course_limited_and_ambiguous_names_fail \
  tests/test_chat.py::test_chat_log_keeps_answer_scope_and_visible_version \
  tests/test_chat.py::test_global_cli_selection_and_scope_commands \
  tests/test_rag_api.py::test_search_endpoint_calls_retriever_with_scope \
  tests/test_retriever.py::test_search_passes_course_and_document_scope
```

实际结果为 `6 passed in 1.30s`。各断言证明：

- 同课程中可用编号或唯一文件标识选文件；同名文件不猜测。`/file` 固定文档，`/all` 回到当前课程，`/global` 清空全局范围。
- 回答引用不存在的证据编号时产生明确 `citation_warning`。JSONL 日志保留答案、有效范围下的可见版本、命中页号、路由和是否执行检索。
- HTTP 测试使用 `httpx.ASGITransport` 和依赖覆盖，没有打开网络套接字。`POST /api/rag/search` 返回 200，并保留 query、课程、文档、Cell；`top_k=5`、课程/文档范围、contextual 模式和一条历史消息各传入一次检索器。
- Retriever 将两个课程 ID、一个文档 ID 和 `top_k=5` 传给旧混合检索，旧召回上限为 `min(top_k * 3, 50) = 15`。

这些用例验证现有兼容调用契约。它们没有声称真实 Qdrant、模型回答或视觉读取可用。
