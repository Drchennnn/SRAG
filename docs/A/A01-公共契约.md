## 2. 发布身份与可见性

- **资料**由 B 登记。输入为经授权的课程、文件字节及登记动作，输出为稳定 `document_id` 和版本记录。一个资料 ID 在本地资料库内唯一，持有一个 `course_id`。改标题/路径由登记动作显式关联资料 ID；仅凭同名、同路径或同字节都无法跨课归并。旧 ID 通过有归属的映射指向新资料和已核对的版本，未核对的旧引用只保留原标签并标记无法确认版本。
- **版本**由 `(document_id, version)` 标识。正整数版本首次关联该资料的新字节时分配，`content_sha256` 是原文件字节完整 SHA-256。重复导入同内容复用身份与原件；重新发布已保留的相同内容可复用历史版本。排序和并发使用单调发布代次 `publication_epoch`，避免将最大版本号当当前版本。重新解析或渲染用独立的派生代次，源定位一致的对象 ID 在同版内须稳定；若纠正源定位，保留历史映射或报告失效。旧 `force` 仍可重做派生数据，旧版号和新身份的转换由 B 设计。
- **新检索**固定授权范围与可见快照，候选须是已发布、未删除且已到 release_at 的当前版。待发布/失败版不会挤掉已有可用版；预约发布前旧版仍可见。切换、撤下或删后重建递增代次。B 在提交晚到派生数据时核对资料、版本、原件哈希、预期代次和当前可见状态；不匹配则丢弃本次公开写入。提交跨层证据前重新检查权限；已撤下或改版的新查询须按最新范围重查或报告本轮已失效。
- **历史访问**从授权会话中稳定的消息引用进入，只查原指向版本。仍保留且获准的历史原件可读；只剩元数据时给 `original_unavailable` 和原因，无访问授权的请求返回 `not_accessible` 且不泄漏文件信息。明确打开新版是一次新选择。删除动作能撤销搜索与历史访问；历史元数据按仍具备的权限呈现。版本记录与原件保存是 B 的职责，D 验证实际读取字节与声明版本相符。

## 3. 来源对象及位置

B 发布对象登记，C 返回候选引用，D 返回精确原件或明确的回退，E 将引用保存到消息，F 按同一标识去重与补证据。跨层键为 `(document_id, version, source_id)`，再用该版本的 `content_sha256` 校验原件。JSON 引用至少带三元组；`course_id` 由版本登记核对，客户端传值不能授权。单个 `source_id` 仅在版本内稳定，编号、人类标题、路径、`chunk_id`、媒体哈希和排序均不能替代它。旧命中 `chunk_id` 可作为诊断线索；一个块可落在多个来源，单个来源可支持多个块。父级引用限定在同一资料版本内。

| kind | 原件定位 | 父级及降级 |
| --- | --- | --- |
| `page` | PDF 页/PPTX 幻灯片顺序，从 1 开始，无对象框 | 课程结构可另记录章节；整页渲染失败时给页号和可用原生文字 |
| `page_object` | 有 `page` 与页内定位。PPTX 可用原生 shape ID 路径（分组从外到内）；PDF 可用已保存的版内定位记录，并记录其解析来源。表、公式、子图属于此类 | 父键为同页或该页上的已登记父图。框不可靠或子图无法确认时退到可靠父图/整页或澄清；结果标明实际打开的对象及原因 |
| `cell` | `cell_index` 是原 notebook 数组零基索引，另外携带原件中有效且唯一的 `cell_id`（可空）。界面 Cell 序号由索引 +1 | 无有效唯一 ID 时在同版按原始索引定位。迁移先核对原件 JSON，避免依赖读取工具补出的 ID |
| `notebook_output` | 父键是代码 Cell；`output_index` 是原始 `outputs` 数组零基序号，保留 stream、空输出等前项的位置 | 一个 MIME bundle 是一个输出对象，内含的表示由 MIME 类型再区分。同一 Cell 两张独立图位于不同输出项。截去部分位图仍属于该输出的派生表示，禁止把同 Cell 另一输出当作回退图。 |

页内区域使用 `bbox = [left, top, right, bottom]`，均在 0–1，原点左上。坐标系 `visible_page_norm_v1` 指经旋转和裁边后的可见页，另存原坐标至显示坐标变换及其版本。先在父页坐标合成组变换，再将边界投影并记录可靠性。表格区域须保留必要表头/单位，子图须核对图例、轴和图注；不能可靠确定时不标精裁。裁切左上向下取整、右下向上取整并夹在同版渲染尺寸内。独立输出不借用页号或页框，默认读所选完整 MIME 表示。媒体字节可去重，各次出现的来源身份仍分开。

## 4. 消息、实际展示和读取

- **证据与显示。** E 持久化授权会话内的 `message_id`、有序块和按 `evidence_id` 索引的本消息证据。证据含原请求来源及实际读取记录。每个显示块有消息作用域内唯一的 `display_id`、所支持的 `evidence_id` 和实际 `display_source`。同一对象在消息内显示两次产生两个 `display_id`；两次可共用一个来源和字节。实际打开父级时保留目标与回退理由，显示与追问锚定实际父级，不能借父级展示断言目标已选中或已读。渲染产物另有规格、渲染器版本、尺寸及字节哈希。
- **追问与授权。** 点卡片发送 `message_id + display_id`，服务在所属会话取实际来源并二次核验。自然语言的“第二张图”按已完成消息中实际可见图像块顺序解析，文字、加载占位和失败卡不占图序号。同一条消息的可见顺序可在刷新后重建。消息/图序不确定时澄清；找不到指针时报告不可用。媒体访问只接受已登记引用与规格并验证权限及原件，无需让浏览器取得本机路径。
- **读取记录。** `read_status` 为 `not_attempted | succeeded | partial | failed`，随本轮证据记录；每次实际读取另存 `actual_source`、`method`（`native_text | native_table | ocr | vision`）、结果状态与缺项或失败原因。OCR/视觉记录输入图的 MIME、渲染规格、字节哈希（与原件哈希分开）、模型/管线与提示版本；定向视觉还含问题身份。显示图片、命中邻页、已有机器转写和本轮读取原图分别留痕。缓存只在原件、对象、规格、输入字节、管线版本及适用的问题一致时复用，并标记命中。部分/失败只支持实际读到的内容。可复用转写可向 B 申请写回；定向解释留在该轮。
- **失败。** 错版本、错课程、框失真、输出项无图、渲染/模型失败或引用不可访问都保留原因。禁止用当前版、同名文件、邻图替换历史精确定位。用户可显式另选，系统可给符合授权的父级或可读文字，同时记录真实回退。
