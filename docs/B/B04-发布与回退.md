# B04 · SQLite 本地发布、兼容与回退

B04 以 [B01](./B01-发布设计.md) 的已签契约为准。Codex 主会话负责共享模型、SQLite 发布与可见性桥、导入服务和隔离事务测试，`b03` 实现旧资料映射，`b02` 实现 HTTP 和搜索切换。基线是 HEAD `33fad8ea339222574780d56ab401d0ed779369a8` 加 [接手工作区](./接手版本.json)。送审时锁定源码见 [送审版本](./B04-送审版本.json)。

## 变更入口

- [解析快照与服务](../../app/rag/local_library.py) 从所选路径读取不可变快照，保留原名解析器上下文，对每份资料分别提交。目录遍历、解析失败、权限内路径以及隔离数据目录均有用例。
- [SQLite 发布](../../app/stores/local_library.py) 用事务写原件、来源结构与 FTS 行后切换指针。新旧版本的精确读取需通过文档与 course 校验。相同内容去重、重新发布、路径变更、删除及到期提升均核对发布代次。文本增强写回时检查对应当前资料、版本、哈希、来源与代次。
- [旧资料转换](../../app/rag/local_migration.py) 支持旧库的活动快照及带完整 SHA-256 的课件包。旧 chunk、element、asset 可定位到已验证对象或受证据支持的父页/Cell。缺原件时旧正文标为 `legacy_text`，原件回读给出 `original_unavailable`。
- [本地 HTTP](../../app/api/local_library.py) 提供导入、搜索、迁移与删除。旧 `/search` 默认走原向量路由，`RAG_SEARCH_BACKEND=local` 提供文字切换。旧目录、全文读取和向量候选在 SQLite 内核对已映射版本，切回时禁止过时版本重新可见。

## 隔离回放

| 场景 | 当前搜索 | 历史原件 |
| --- | --- | --- |
| 同字节重导与移动 | 复用文档/版本；同路径不同课程隔离，显式移走后旧路径是登记别名 | 原字节与版内来源仍可读取 |
| 一次成功换版与切回相同内容 | 当前只命中新版；重新发布旧字节后复用版号、提升代次 | 两版各取得各自原件；无 course 授权不给元数据 |
| FTS 写入后故障 | 独立连接只见旧版，错误返回后新结构、原件和 FTS 无残留；重试成功 | 失败版不可访问，旧引用继续可读 |
| 预约发布 | 新计划替换旧待定项。到期前保持 v1；以当前内容再预约也能替换其他待定项，第一次到期后只见已选当前版 | 未发布待定版本不可读，已发布版本可独立读 |
| 替换/删除后迟到写回 | 过期版、错哈希、错 scope、删后写回与重导后的旧代次均拒绝；合法增强保留派生来源标记 | 删除后撤销读取；显式重导后才恢复当前归属与读取 |
| 旧 SQLite、课件包回填与切回 | 有同版本旧向量时兼容可见。新当前版无等价 alias 时旧 v1 隐藏；同字节切回后可再用旧版 | 旧来源映射后读取精确原件；失去原件的课件包只回退父页，恢复同字节时原版可回读；重新核对旧包后可将父页映射精化到唯一原生对象 |
