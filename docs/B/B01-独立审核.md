## 初始修订必须修正

1. **补齐稳定身份和路径别名规则。** 规定首次未传 `document_id` 时如何生成并只持久化一次，说明 ID 格式、冲突重试和课程归属不可变规则。为曾登记路径定义归一化、唯一键、历史别名和显式移动后的旧路径行为。明确同字节只在同一已确认资料内复用版本，不能靠路径或哈希跨资料合并。
2. **给出可执行的发布表与预约发布状态机。** 至少列出资料、路径别名、版本/原件、发布记录或当前指针、来源、FTS、增强和 legacy 映射的主键、外键及关键唯一约束。定义无预约、单个及多个预约、即时换版、取消预约、删除和同内容历史复用时的权威版本选择顺序。版本、`publication_epoch`、可见性和 FTS 必须在一次读快照中一致。若采用读时到期选择，代次必须在准备事务中确定且选择器能返回对应代次。若采用定时写切换，应给出无后台任务时的补偿入口和幂等规则。
3. **落地 legacy 可见性桥。** 明确旧 `/api/rag/search`、老 CLI 和直接 Retriever 的过滤函数从哪张表或兼容视图取得允许的旧 `(document_id, version)`。当前 local 版没有等价旧向量映射时允许集合必须为空，不能退回旧 active v1。说明切回 legacy 只换召回实现，不换授权/当前版判定，并覆盖删除、重新导入和旧库未迁移资料。
4. **冻结并行解析器共用的来源和 FTS 约束。** 给 `source_id` 至少定义 kind 命名空间、由哪些规范化 locator 字段构造、重复/碰撞时的失败规则和同版重解析稳定性。定义一个来源可以有几行原生 FTS 与派生 FTS、行的稳定键和 provenance 更新规则，保证 B02/B03 的输出可由 B04 无歧义发布。

## 已验证的事务前提

在隔离临时 SQLite 3.53.1 中创建当前指针表和 FTS5 表。连接 A 执行 `BEGIN IMMEDIATE` 后把 v1 指针改为 v2并插入新 FTS 行，连接 B 同时读取仍得到 v1，连接 B 的第二个 `BEGIN IMMEDIATE` 返回 `database is locked`。连接 A rollback 后，B 仍读到 v1，查询新 FTS 行计数为 0。

复现命令：

```bash
.venv/bin/python - <<'PY'
import sqlite3, tempfile
from pathlib import Path
with tempfile.TemporaryDirectory() as d:
    p = Path(d) / "probe.sqlite"
    a = sqlite3.connect(p, isolation_level=None)
    b = sqlite3.connect(p, isolation_level=None, timeout=0.05)
    a.executescript("CREATE TABLE current(doc TEXT PRIMARY KEY, ver INT); INSERT INTO current VALUES('d',1); CREATE VIRTUAL TABLE f USING fts5(doc,ver UNINDEXED,text); INSERT INTO f VALUES('d',1,'old');")
    a.execute("BEGIN IMMEDIATE")
    a.execute("UPDATE current SET ver=2 WHERE doc='d'")
    a.execute("INSERT INTO f VALUES('d',2,'new')")
    print(b.execute("SELECT ver FROM current WHERE doc='d'").fetchone()[0])
    try:
        b.execute("BEGIN IMMEDIATE")
    except sqlite3.OperationalError as exc:
        print(exc)
    a.rollback()
    print(b.execute("SELECT ver FROM current WHERE doc='d'").fetchone()[0])
    print(b.execute("SELECT count(*) FROM f WHERE f MATCH 'new'").fetchone()[0])
PY
```

预期输出的关键值依次为 `1`、`database is locked`、`1`、`0`。这只证明 SQLite 原子事务前提可用，不替代上述状态机、表约束和兼容过滤的设计证明。
